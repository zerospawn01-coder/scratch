# EA-AOL Language Specification License

The **EA-AOL Language Specification** (including grammar, semantics, and protocol definitions) is dedicated to the public domain under the **CC0 1.0 Universal** license.

## CC0 1.0 Universal

This means:

- ✅ **No copyright** - The specification is in the public domain
- ✅ **No patents** - No patent claims on the language itself
- ✅ **No restrictions** - Anyone can implement EA-AOL freely
- ✅ **Commercial use** - Build proprietary implementations
- ✅ **Modifications** - Extend or adapt the specification

## Covered Documents

- `docs/EA-AOL-v0.1-Specification.md`
- `spec/orchestrator.proto` (protocol definition)
- BNF grammar definitions
- Semantic specifications

The **reference implementation** (code in `compiler/`, `runtime/`, etc.) is licensed under **BSD-2-Clause** (see `LICENSE` file).
