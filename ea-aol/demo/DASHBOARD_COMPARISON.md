# EA-AOL Dashboard Comparison

## 📊 2つのバージョン

### 1. グラフィカル版 (`amd_live_dashboard.py`)

**特徴**:
- ✅ 美しいグラフ表示
- ✅ リアルタイム更新
- ✅ 複数メトリクス同時表示
- ✅ SF風デザイン

**リソース使用量**:
- CPU: 15-30%
- メモリ: 150-200MB
- GPU: 5-10% (描画負荷)

**用途**:
- プレゼンテーション
- デモ動画撮影（高品質）
- 詳細分析

**起動**:
```bash
python demo\amd_live_dashboard.py
```

---

### 2. 軽量版 (`amd_lightweight_dashboard.py`)

**特徴**:
- ✅ ターミナル表示のみ
- ✅ 最小限のリソース使用
- ✅ 高速更新
- ✅ GPUへの影響なし

**リソース使用量**:
- CPU: 1-3%
- メモリ: 20-30MB
- GPU: 0% (描画なし)

**用途**:
- 実機テスト
- 長時間監視
- 低負荷デモ

**起動**:
```bash
python demo\amd_lightweight_dashboard.py
```

---

## 🎯 推奨用途

### デモ動画撮影の場合

| 目的 | 推奨版 | 理由 |
|------|--------|------|
| **視覚的インパクト** | グラフィカル版 | 美しいグラフ、SF風UI |
| **GPU負荷を見せる** | 軽量版 | GPUへの影響が最小 |
| **長時間録画** | 軽量版 | 安定性が高い |
| **プレゼン用** | グラフィカル版 | 見栄えが良い |

### 実機テストの場合

| 目的 | 推奨版 | 理由 |
|------|--------|------|
| **実際の制御効果** | 軽量版 | 測定への影響が最小 |
| **データ収集** | 軽量版 | ログ出力が簡単 |
| **デバッグ** | 軽量版 | 数値が見やすい |
