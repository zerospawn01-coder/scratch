# CRISIS ACTOR: The Rehearsal State
**v0.2.1 P0 Test Edition**

『CRISIS ACTOR』は、危機演出チームが白カードとして嘘の公式ログを固定し、灰カードとして未処理の矛盾を腐らせ、黒カードとして真実を未来へ封印し、粗い演出カードとして雑な処理の責任を個人に刻むTRPGである。

> **プレイヤーは、「成功するか失敗するか」ではなく、「どのカードとして未来に残すか」を選ぶ。**

---

## 【P0】プレイング・ガイドライン（完全架空・風刺対象の明示）

> [!WARNING]
> 本作は純粋なフィクションとして設計された心理サスペンスTRPGであり、実在の事件・災害・被害者を題材にしません。
>
> 作中の「クライシスアクター」は、現実の被害者を偽物扱いする陰謀論ではなく、架空社会における危機管理PR、組織的隠蔽、行政的記録操作を風刺するためのフィクション上の概念です。
> このゲームは被害者や証言者を疑うためのゲームではありません。被害や証言が「形式を満たさない」という理由で無力化される構造を批判対象とします。
>
> すべてのシナリオは「架空の都市」「架空の企業」による「架空の演習」として扱ってください。

## 1. 共有パラメータ（P0クロック制）

P0テストでは以下の5つの「クロック（0〜6）」、「未処理負債」、および「予算」を使用する。

*   **信憑性 (0〜6)**: 演出が本物と信じられているか。
*   **現実混入率 (0〜6)**: 演出に本物の惨劇が混ざっている度合い。
*   **監査負債 (0〜6)**: 嘘を強引に固定したツケ。
*   **共犯クロック (0〜6)**: 倫理監査役専用。沈黙と見逃しの罪。各シナリオで名称が変わる（検証委員会 / 文化財処理 / 公開審査）。
*   **機材劣化 (0〜6)**: 特効機材の消耗。
*   **未処理負債 (0〜10)**: GM用隠しパラメータ（構造負債）。プレイヤーに数値は公開されない。嘘の代償、手抜きのツケが蓄積した裏の値。
*   **予算 (トークン)**: 判定の支援や隠蔽に使用するリソース。

## 2. 判定システムと「B級処理」

PCは以下の4つの能力値を持つ。
*   **脚本**: 演出の妥当性、台本の整合性、論理的説得。
*   **演出**: 特効機材の操作、キャストの誘導、現場での即興アクション。
*   **情報**: 物的証拠の調査、カメラ・通信機器の操作、データの記録・隠蔽。
*   **精神**: NPCへの心理誘導、緊迫した交渉、恐怖やノイズへの抵抗。

判定は、行動に対応する【能力値】の数だけD6を振る。難易度は通常1または2。

*   **5（クリーン成功）**: 成功数+1。副作用なし。
*   **6（派手な成功）**: 成功数+1。**信憑性+1、ただし現実混入率+1**。
*   **1（ノイズ）**: 1が**2個以上**出たらノイズ発生。灰カードが1枚発生、または既存の灰カードの腐爛が+1される。
*   **2〜4（空振り）**: 何も起きない。
*   **成功数不足（失敗）**: 行動失敗。信憑性-1、または灰カード1枚発生。

### 【B級処理】（意図的な妥協）
プレイヤーは判定前に「B級処理」を宣言できる。

*   **効果**: 「6」が出たことによる**現実混入率+1を無効化**できる。
*   **代償**: **「粗い演出カード（灰カード）」を1枚作成**する。また、その判定では信憑性+1を得られない。

## 3. カードシステムと記憶装置

### 【白カード】公式ログ（世界が信じた嘘）
セッション終了時、必ず**3枚**作成する。
1. 公式に成功したこと
2. 隠された矛盾を含む公式説明
3. **次回以降の前提になる嘘（最も重要。次回のルールになる）**
   *(例: この商業施設の避難手順は、都市全域に展開可能な成功モデルである)*

#### 支配的白カード（キャンペーン用GM負荷対策）
キャンペーンが進むほど過去の白カード（嘘）が蓄積し、GMの管理負荷が上がります。この対策として、支配的白カードルールを適用します。
*   **ルール**: セッション開始時、前回までの白カードから最大3枚を選び、今回の「支配的白カード」とする。今回のシナリオでは、選ばれなかった白カードの整合性確認を一時的に免除する。
*   **効果**: 
    - 支配的白カードに反するPCの行動は、判定の難易度+1。
    - 支配的白カードに沿う隠蔽処理は、信憑性+1。
    - ただし、その支配的白カードに対応する黒カードが露出した場合、未処理負債+2。

#### 白カード整合性クロック（嘘の崩壊）
キャンペーン終盤では、GMがすべての嘘を矛盾なく管理しきるのではなく、嘘が矛盾して崩壊していくプロセス自体をクライマックス装置として機能させます。
*   **整合性クロック：0〜6**
    - **0**: 整合（公式説明に矛盾はない）
    - **1**: 軽微な矛盾（細かい数字の食い違い）
    - **2**: 記録齟齬（公式記録間のデータ不一致）
    - **3**: 公式説明の重複（同じ事実に対し複数の不自然な説明）
    - **4**: 相互矛盾（A機関とB機関の主張が真っ向から対立）
    - **5**: 複数機関の説明不一致（誰も辻褄を合わせられなくなる）
    - **6**: 公式ナラティブ崩壊（システム全体の嘘が公に崩壊し、白カードが全て無効化される）

### 【灰カード】未処理の矛盾と「腐爛」
「1」の連続や行動失敗で発生する不穏な事実。放置すると環境を汚染する。
灰カードには**「腐爛（0 / 1 / 2）」**の段階がある。

*   **腐爛0**: ただの違和感。まだ処理可能。
*   **腐爛1**: 現場にノイズが出る。NPCの台詞・映像に異物感が混ざる。
*   **腐爛2**: 強制発火。現実混入イベント、または白カード侵食が発生する。

**【腐爛の進行と処理】**
各フェーズ終了時、場に残った灰カードを**1枚だけ**選び、腐爛を+1する。プレイヤーは灰カードに対し以下の処理を選べる。
*   **修正**: 予算-1または判定で除去。
*   **隠蔽**: 監査負債+1で除去。
*   **演出に取り込む**: 白カード化（現実混入率+1）。
*   **Black Ledgerへ封印**: 黒カード化。
*   **放置**: 何もしない（腐爛進行の対象になる）。

### 【粗い演出カード】B級処理の代償
B級処理を行った際に発生する特殊な灰カード。以下を記述する。
*   **担当PC / 発生場面 / 何が粗かったか / 誰に見られた可能性があるか / 後で突かれる弱点**

### 【黒カード】裏ログ（封印された真実）
倫理監査役のみが記述・秘匿し、最終章で白カードを破壊するために使う。
*   **破壊不能**: 黒カードは一度記録されるとゲーム中破壊できない。
*   **無力化**: 他のPCが黒カードの主張を否定する「対応する白カード」を固定した場合、その黒カードは「無力化（保留）」される。無力化された黒カードは最終解決フェーズまで効果を発揮できない（白カードによる隠蔽が成功している状態となる）。
*   **記述項目**: 表向きの公式事実 / 実際に起きたこと / 証拠の種類 / 関与PC / 開示した場合に壊れる（または対立する）白カード

## 4. 対立制御・倫理監査役とP0ルールカーネル

この章では、GMの裁量依存を排し、ゲームの進行と緊張感を機械的に制御するためのルール（P0ルールカーネル）を定義する。

### 4.1. セッション終了条件と結末評価

#### 【セッション終了条件（クライマックス移行トリガー）】
以下のいずれかの条件を満たした時点で、即座にゲームはクライマックス（最終解決フェーズ）に移行する。
1. シナリオの **Phase 4** に到達した。
2. **現実混入率が 6** に到達した。
3. **共犯クロック（検証/文化財/処理クロック）が 6** に到達した。
4. 確定した **黒カードが 3枚以上** 場に残った。
5. GMが物語上「公式処理の最終期限（タイムリミット）」を宣言した。

#### 【結末評価（3軸評価システム）】
ゲームは単純な勝敗ではなく、セッション終了時の最終カード状態やクロック値から、以下の3つの指標で結末（アウトカム）を判定する。

*   **Public Outcome（社会／公式評価）**:
    - **成功**: 最終的に「白カード」3枚が公式記録として固定され、外部への隠蔽が成立した。
    - **失敗**: 現実混入率の爆発、あるいは告発によって公式説明が破綻した。
*   **Audit Outcome（監査／記録評価）**:
    - **成功**: 黒カード、非公開監査ログ、調査対象カードによって「消せない真実」が裏の記録として未来に残った。
    - **失敗**: 真実が完全に白塗り（無力化）され、監査の痕跡すら消滅した。
*   **Human Outcome（人間性評価）**:
    - **成功**: NPCやPCが、行政やシステムの単なる「処理オブジェクト（形式）」として消費されず、一人の人間として扱われた。
    - **失敗**: 記録上の辻褄合わせのために被害や名前が消去・改ざんされた。

### 4.2. 未処理負債（Structural Debt）カウンター

未処理負債は、危機演出チームがその場の安心（信憑性の確保、現実混入の回避、強行解決）を買った代金として蓄積する裏のパラメータである。GMはこれを記録し、以下のルールに従って増減させる。

#### 【未処理負債の増加（+）トリガー】
| 発生する処理・行動 | 加算値 |
| :--- | :---: |
| 灰カード（矛盾）を処理・隠蔽せず、放置したままフェーズが終了した | **+1** |
| 灰カードを白カード（公式ログ）で上書き・吸収した | **+1** |
| 黒カード（真実）を白カードによって無力化（隠蔽）した | **+2** |
| クライマックスの黒塗り処理で「黒塗り理由コード」を使用した | **+1** / 回 |
| 既往症ラベル、表現調整ガイドライン、演出用ノイズ処理などを適用した | **+1** / 回 |
| B級処理を宣言し、現実混入率の上昇を回避した | **+1** |
| 粗い演出カードを処理（解決）しないまま、次のフェーズへ進んだ | **+1** |
| 倫理監査役（オーディター）の異議申立を、ディレクターが強行却下した | **+1** |
| 判定で「6」を含む派手な成功によってシーンを解決した | **+1** |
| 監査ログ（黒カードなど）を「非公開保管（SEALED/LIMITED）」に回した | **+1** |

#### 【未処理負債の減少（-）トリガー】
| 発生する処理・行動 | 減算値 |
| :--- | :---: |
| 灰カード（矛盾）をPCが調査し、黒カード（真実）へと昇格・固定させた | **-1** |
| 黒カードを「調査対象カード」として公的に保護した | **-1** |
| NPCの証言を「演出物（ノイズ）」として排除せず、真摯に扱った | **-1** |
| 固定された白カードの一部を「限定暴露」することを選択した | **-1** |
| 倫理監査役（オーディター）が Witness Claim を成功させた | **-1** |
| Emergency Injunction によって対象カードを保全した | **-1** |

*※未処理負債の下限値は 0 とする。*

#### 【未処理負債の帯域と環境への影響】
未処理負債の累積値に応じて、セッション全体の環境圧力と発生する効果が以下のように決定される。

*   **0〜2 【安定（Stable）】**: ノイズは軽微。環境は制御下にある。
*   **3〜4 【圧力（Pressure）】**: 現場が軋み始める。**フェーズ終了時に必ず「ノイズ」が1件発生**する。
*   **5〜6 【破綻前（Impending Collapse）】**: 演出に明らかな異常。GMは**「異常混入イベント表」から1件を発生**させる。
*   **7〜8 【破綻（Collapse）】**: 制御不能寸前。**場にある灰カード1枚が強制的に「腐爛+1」**される。
*   **9以上 【強制クライマックス（Forced Climax）】**: システムの防壁が崩壊。**黒カードが世間に漏洩するか、現実混入イベントが表面化し、即座に最終解決（終了条件）へ移行**する。

### 4.3. 異常混入のトリガーとイベント表

#### 【異常混入の発生トリガー】
以下のいずれかの条件を満たしたとき、GMは「異常混入イベント」を発動しなければならない。
1. 未処理負債が **5以上** になった。
2. 現実混入率が **3 / 5 / 6** に到達した。
3. フェーズ終了時に **「腐爛2」の灰カードが残存** している。

#### 【異常混入イベント表 (1D6)】
GMはシナリオの状況に応じて1つを選択するか、1D6を振って決定する。

1.  **映像・音声素材の汚染**: 編集・配信中の映像や音声素材に、不可解な未分類フレーム（死者のノイズ、奇妙な人影）が混入する。
2.  **NPCの暴走**: NPCが演出台本にない、狂気や恐怖、あるいは過去の隠蔽を示唆する証言を現場で突然語り始める。
3.  **記録の齟齬**: 手元にある公式書類の数値と、現場カメラの記録数値や物証のデータが機械的・論理的に一致しなくなる。
4.  **のぞみ型NPCの拡散**: 外部の陰謀論配信者や野良のオーディター（のぞみ型NPCなど）が、隠蔽前の「一次データ」をSNS上に拡散し始める。
5.  **責任の露呈**: 「粗い演出カード」の原因となった処理の責任PCが、関係者や報道、監査側によって特定され、追及を受ける。
6.  **真実の漏洩**: 黒カードの候補（封印された真実）の一部が、作成中の白カード（公式文面）の隙間から不自然に露出・推測可能な状態になる。

### 4.4. 情報の公開範囲と黒カードの開示

#### 【カード種別ごとの情報公開範囲】
情報の非対称性を維持しつつゲームを運用するため、カードごとに以下の公開範囲を設定する。

*   **白カード（公式ログ）**: **【全員公開】**。公式に固定された事実であり、全員が前提として共有・利用できる。
*   **灰カード（未処理の矛盾）**: **【全員公開】**。現場の違和感や処理すべき問題として、全員の目の前に晒されている。
*   **黒カード（裏ログ／真実）**: **【原則：オーディターとGMのみ】**。他PC（演出チーム）からは見えず、監査ログ（Black Ledger）にのみ秘匿記録される。
*   **粗い演出カード**: **【タイトルのみ全員公開、詳細は担当PCとGMのみ】**。誰のどのような手抜きかが後で揉める材料として、詳細は伏せられる。
*   **疑惑カード（世論ノイズ）**: **【全員公開】**。世間やSNSを飛び交う噂。誰もが知っているが公式には否定されている。
*   **調査対象カード**: **【全員公開】**。公的アーカイブとして保護申請されており、白カードで勝手に上書き（抹消）できない状態のカード。

#### 【黒カードの全体公開（開示）トリガー】
秘匿されている黒カードは、以下のいずれかの条件を満たしたときに全体に強制開示（全員公開）される。
1. 倫理監査役が **Witness Claim** を行い、これを確定・公開した。
2. クライマックスの分岐選択において、黒カードが「結末の判定材料」になった。
3. **現実混入率が 5以上** に到達し、演出そのものが破綻し始めた。
4. シナリオ固有の **監査ログ開示イベント**（監査クロックの進行等）が発生した。

### 4.5. 倫理監査役（オーディター）の機械的権限

倫理監査役が単なる傍観者（良心）にならず、演出の固定（隠蔽）に対抗して未来に「消せない傷」を刻むため、以下の機械的権限を付与する。

#### 1. Witness Claim（真実の刻印） 【1セッション 3回まで】
*   **対象**: 灰カード、NPCの生証言、診断書カード、祭文カードのいずれか1つ。
*   **効果**: 対象を「黒カード候補（真実）」としてその場に固定し、全員に公開する。この効果を受けたカードは、**同じフェーズ中、他のPCが白カード（公式ログ）で上書き・隠蔽することができない**。
*   *※共犯クロックが3以上の場合、この実行に追加コスト（予算1）が必要となる。*

#### 2. Black Seal（監査ログ保護） 【1セッション 1回のみ】
*   **対象**: 確定した黒カード1枚。
*   **効果**: その黒カードを「黒塗り不可（保護）」として監査ログに永久固定する。これにより、たとえクライマックスでAエンド（完全隠蔽）が選択されたとしても、**その黒カードは完全に抹消されず、公開区分「SEALED（封印）」または「LIMITED（限定開示）」として監査ログに残り続ける**。

#### 3. Objection Round（異議申立ラウンド） 【回数無制限】
ディレクター（PC1）が強行決定（5分ルールの適用など）を行った際、オーディターは異議申立ラウンドを宣言できる。
*   **手順**:
    1.  ディレクターが「その隠蔽が現在もたらす組織的利益」を主張する。
    2.  オーディターが「その隠蔽が未来にもたらす監査リスク」を主張する。
    3.  対立の結果、ディレクター以外のPCは、今回の強行によって生じる矛盾を「灰カード」または「黒カード候補」として1枚作成して場に配置できる。
    4.  最終決定はディレクターがそのまま実行する。
    5.  代償として、組織の **監査負債が +1** される。

#### 4. Emergency Injunction（緊急差止命令） 【1セッション 1回のみ】
オーディターは、現在進行中の白カード化・黒塗り・クロック進行・カード無力化を即時停止できる。これはゲーム内権限であり、PL自身の精神的安全弁でもある。
*   **効果**:
    1. 対象の隠蔽・無力化処理をそのフェーズ中だけ停止する。
    2. 未処理負債を-1する。
    3. 対象のカード1枚を「保全中」にする。
    4. 次のフェーズ開始時、そのカードは必ずテーブル（議論の議題）に上がる。
*   **「保全中」カードの効果**:
    - 同じフェーズ中、白カード化できない。
    - 黒塗り理由コードを適用できない。
    - クライマックス時、必ずA/B/C選択の直接の対象になる。
*   **推奨される使用タイミング**:
    - 黒カードが白カードへ吸収されそうな時
    - 診断書カードが既往症ラベルで無力化されそうな時
    - 文化財化処理クロックが6へ到達する直前
    - 黒塗り合議で重要な氏名・証言・地名が消されそうな時
    - オーディターPL自身が「この処理は心理的に重すぎる」と感じた時（安全弁としての発動）

### 4.6. クライマックスの黒塗り合議ルール

Aエンド（完全隠蔽・アーカイブ化）を選択した際、残存する黒カードおよび灰カードを白塗り（無害化）するための「黒塗り合議」は、以下の手順に沿って卓全員の交渉として解決する。

#### 【黒塗り交渉プロセス】
残された黒カード・灰カード1枚につき、以下の手順を繰り返す。
1.  **提示**: 対象カードをGMまたはオーディターが読み上げる。
2.  **提案**: ディレクターが、その矛盾や真実を覆い隠すための「最終的な白カード（公式文面）」を提案する。
3.  **分類**: 担当PCが、隠蔽を正当化するための **「黒塗り理由コード」** を1つ選択・適用する。これにより **未処理負債が+1** される。
4.  **監査**: 倫理監査役は、その白塗り・理由コードに対して「承諾」するか「反対（Objection）」するかを宣言する。
5.  **反対時**: 反対を宣言した場合、即座に **Objection Round（異議申立ラウンド）** を行い、交渉する。
6.  **固定**: 合意、あるいは強行によって決定された最終文面を、登録票・完了報告書・展示パネル等に公式記録として記入する。
7.  **記録**: 隠蔽された真実の片鱗と、理由コードの適用結果を「非公開監査ログ」に保存する。

#### 【黒塗り議論の停滞（5分ルール）】
黒塗り文面や理由コードの決定、オーディターの承諾を巡る議論が **5分** を超えた場合、以下の処理を行う。
*   即座に **処理クロック（共犯クロック）を +1** する。
*   その後、以下のいずれかで決着させる。
    - **A. ディレクターによる強行決定**: ディレクターの提案文面で強引に処理し、監査負債+1。
    - **B. スクリプト対決（判定）**: 対立する文面を主張するPC同士で能力値（脚本/演出）によるダイス対決を行い、勝者の文面を採用する。

### 4.7. キャンペーン継続性と次回への持ち越し

『CRISIS ACTOR』のセッション終了時、処理しきれずに残されたカードやパラメータは、次回のセッションの初期状態として以下のように引き継がれる。これにより、前回の隠蔽のツケが次回の新たな脅威として顕在化する。

*   **未処理の灰カード**:
    - 次回セッションの「初期灰カード」としてそのまま場に登場する。その際、**腐爛段階が自動的に +1** された状態から開始される。
*   **無力化されなかった（場に残った）黒カード**:
    - 次回セッションの **初期未処理負債が +1** された状態から開始される。
*   **未処理の粗い演出カード**:
    - 次回セッションの **初期機材劣化が +1** されるか、あるいはその手抜きを目撃した「責任者NPC」が新たな脅威として現場に登場する。
*   **調査対象カード（公的に保護されたカード）**:
    - 次回セッション中、**白カードによる完全上書き（隠蔽）が一切不可能** なオブジェクトとして場に残り続ける。
*   **Aエンドで固定された白カード**:
    - 次回セッションの「前提ルール（初期白カード）」として場に固定され、PCの行動の足枷（ルール上の制約）となる。
*   **非公開監査ログ**:
    - 次回セッション中、**倫理監査役（オーディター）のみ** が最初から閲覧・参照できる「過去の物証・武器」として機能する。
*   **疑惑カード（世論ノイズ）**:
    - 次回セッションにおいて、のぞみ型NPCが動画で拡散するネタ、あるいは初期世論ノイズ（難易度上昇要因）として再登場する。

## 7. P0 Safety & Debrief Kernel（プレイヤー保護と安全運用）

本作は「記録の改ざん」「被害の無力化」という社会的な暴力をテーマとして扱うため、ゲーム外におけるプレイヤーの安全を保障する仕組み（セーフティ・カーネル）をルールとして必須化します。

### ① 風刺対象の厳格な分離
*   ゲーム内で構築・提示される「陰謀論カード」は、被害者を傷つけるためのものではなく、行政や組織の制度的暴力を可視化するための「歪んだ対抗物語」として扱います。
*   実在の事件や現在進行形の被害をゲーム内に持ち込むことは厳禁です。

### ② Audit Pause（卓外での安全一時停止）
*   オーディターPLは、重い判断や心理的負荷を一人で背負う必要はありません。
*   **ルール**: オーディターPLは、1セッション中に2回まで、ゲーム内の時間を止めて「Audit Pause」を宣言し、卓外での相談（プレイヤーとしてのケア確認）を要求できます。
*   **安全の保障**: Audit Pauseの間は、ゲーム内の処理クロック（文化財化クロック等）は進行せず、未処理負債も増えません。プレイヤー本人の負荷・不快感・続行可能性の確認のみに時間を使用します。

### ③ 卓外安全とゲーム内圧力の完全な分離
*   プレイヤーが「ゲーム上不利になる」ことを恐れて安全申告を躊躇しないよう、以下の原則を徹底します。
*   **原則**: **安全確認、プレイヤーの休憩、Xカードの使用、Audit Pause、およびセッション後のDebriefは、ゲーム内の「停滞」とはみなされません。** これらによって処理クロック、未処理負債、現実混入率は一切上昇しません。

### ④ Fiction Close（フィクションの切断儀式）
セッション終了時、GMは必ず以下の「切断儀式」を口頭で執り行ってください。
1. 今日扱った事件・組織・被害者はすべて架空であり、現実とは無関係であることを確認する。
2. 作中で構築された陰謀論は、真実ではなくフィクション上の記号であることを確認する。
3. 実在の事件との接続（卓外への感情の持ち出し）を禁止することを確認する。
4. 各PLに「重かった場面」「持ち帰りたくない感情」「次回避けたい描写」をヒアリングする。

> *「この卓で作られた陰謀論は、現実を説明するものではない。架空の制度的暴力を可視化するための道具である。」*

### ⑤ Debrief（デブリーフィング）の必須実施
セッション終了後、GMは全員に対し、以下の **「Debrief 3問」** を必ず質問してください。回答は短くて構いません。ゲーム内の共犯関係を卓外へ持ち越さないための防波堤です。
1. **「今日、ゲームとして面白かったが、心理的に重かった処理や描写はどこだったか？」**
2. **「次回以降のセッションでも扱ってよい要素と、逆に避けたい（NGにしたい）要素は何か？」**
3. **「PC（キャラクター）の視点ではなく、PL（プレイヤー自身）として、現在の気分や精神状態は安全か？」**

### ⑥ 役職ローテーション（キャンペーン用）
同じプレイヤーに心理的負荷が集中するのを防ぐため、キャンペーンでは役職の交代を推奨します。
*   **ルール**: キャンペーンでは、原則2セッションごとにオーディター（倫理監査役）の交代を提案します。
*   **負荷確認**: 同じPLが3セッション以上連続でオーディターを担当する場合、セッション開始前にGMは必ず個別で負荷確認を行ってください。
*   **事前推奨**: 単発セッションの場合、オーディターは最も重い情報を扱うため希望者制とし、初心者は初回セッションでの選択を避けることを推奨します。
