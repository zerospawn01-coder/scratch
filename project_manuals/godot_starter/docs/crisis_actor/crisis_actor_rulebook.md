# CRISIS ACTOR: The Rehearsal State
**v0.2.1 P0 Test Edition**

『CRISIS ACTOR』は、危機演出チームが白カードとして嘘の公式ログを固定し、灰カードとして未処理の矛盾を腐らせ、黒カードとして真実を未来へ封印し、粗い演出カードとして雑な処理の責任を個人に刻むTRPGである。

> **プレイヤーは、「成功するか失敗するか」ではなく、「どのカードとして未来に残すか」を選ぶ。**

---

## 【P0】プレイング・ガイドライン（完全架空宣言）

> [!WARNING]
> 本作は純粋なフィクションとして設計された心理サスペンスTRPGです。
> 現実の陰謀論や被害者を揶揄・消費する意図はありません。
> すべてのシナリオは「架空の都市」「架空の企業」による「架空の演習」として扱ってください。

---

## 1. 共有パラメータ（P0クロック制）

P0テストでは以下の4つの「クロック（0〜6）」と「予算」を使用する。

*   **信憑性 (0〜6)**: 演出が本物と信じられているか。
*   **現実混入率 (0〜6)**: 演出に本物の惨劇が混ざっている度合い。
*   **監査負債 (0〜6)**: 嘘を強引に固定したツケ。
*   **共犯クロック (0〜6)**: 倫理監査役専用。沈黙と見逃しの罪。
*   **予算 (トークン)**: 判定の支援や隠蔽に使用するリソース。

---

## 2. 判定システムと「B級処理」

PCは以下の4つの能力値を持つ。
*   **脚本**: 演出の妥当性、台本の整合性、論理的説得。
*   **演出**: 特効機材の操作、キャストの誘導、現場での即興アクション。
*   **情報**: 物的証拠の調査、カメラ・通信機器の操作、データの記録・隠蔽。
*   **精神**: NPCへの心理誘導、緊迫した交渉、恐怖やノイズへの抵抗。

判定は、行動に対応する【能力値】の数だけD6を振る。難易度は通常1または2。

*   **5（クリーン成功）**: 成功数+1。副作用なし。
*   **6（派手な成功）**: 成功数+1。**信憑性+1、ただし現実混入率+1**。
*   **1（ノイズ）**: 1が**2個以上**出たらノイズ発生。灰カードが1枚発生、または既存の灰カードの腐爛が+1される。
*   **2〜4（空振り）**: 何も起きない。
*   **成功数不足（失敗）**: 行動失敗。信憑性-1、または灰カード1枚発生。

### 【B級処理】（意図的な妥協）
プレイヤーは判定前に「B級処理」を宣言できる。

*   **効果**: 「6」が出たことによる**現実混入率+1を無効化**できる。
*   **代償**: **「粗い演出カード（灰カード）」を1枚作成**する。また、その判定では信憑性+1を得られない。

## 3. カードシステムと記憶装置

### 【白カード】公式ログ（世界が信じた嘘）
セッション終了時、必ず**3枚**作成する。
1. 公式に成功したこと
2. 隠された矛盾を含む公式説明
3. **次回以降の前提になる嘘（最も重要。次回のルールになる）**
   *(例: この商業施設の避難手順は、都市全域に展開可能な成功モデルである)*

### 【灰カード】未処理の矛盾と「腐爛」
「1」の連続や行動失敗で発生する不穏な事実。放置すると環境を汚染する。
灰カードには**「腐爛（0 / 1 / 2）」**の段階がある。

*   **腐爛0**: ただの違和感。まだ処理可能。
*   **腐爛1**: 現場にノイズが出る。NPCの台詞・映像に異物感が混ざる。
*   **腐爛2**: 強制発火。現実混入イベント、または白カード侵食が発生する。

**【腐爛の進行と処理】**
各フェーズ終了時、場に残った灰カードを**1枚だけ**選び、腐爛を+1する。プレイヤーは灰カードに対し以下の処理を選べる。
*   **修正**: 予算-1または判定で除去。
*   **隠蔽**: 監査負債+1で除去。
*   **演出に取り込む**: 白カード化（現実混入率+1）。
*   **Black Ledgerへ封印**: 黒カード化。
*   **放置**: 何もしない（腐爛進行の対象になる）。

### 【粗い演出カード】B級処理の代償
B級処理を行った際に発生する特殊な灰カード。以下を記述する。
*   **担当PC / 発生場面 / 何が粗かったか / 誰に見られた可能性があるか / 後で突かれる弱点**

### 【黒カード】裏ログ（封印された真実）
倫理監査役のみが記述・秘匿し、最終章で白カードを破壊するために使う。
*   **破壊不能**: 黒カードは一度記録されるとゲーム中破壊できない。
*   **無力化**: 他のPCが黒カードの主張を否定する「対応する白カード」を固定した場合、その黒カードは「無力化（保留）」される。無力化された黒カードは最終解決フェーズまで効果を発揮できない（白カードによる隠蔽が成功している状態となる）。
*   **記述項目**: 表向きの公式事実 / 実際に起きたこと / 証拠の種類 / 関与PC / 開示した場合に壊れる（または対立する）白カード

## 4. 対立制御と倫理監査役

### 異議申立ラウンド（PC間対立）
1. 反対者が異議を述べる。
2. 推進者が反論する。
3. 倫理監査役が未来リスクを提示する。
4. **ディレクターが現在を決定する。**
5. **反対者は灰カードまたは黒カード（未来）に記録できる。**

### 倫理監査役：共犯クロック
倫理監査役は以下の行動をとると**【共犯クロック+1】**される。
*   Witness対象を見逃した / 灰カードを見たのに記録しなかった / 本物の被害を演出物として処理させた / ディレクターの強行処理に異議を出さなかった

**【ペナルティ】**
*   **クロック3**: 発言信用が落ちる。Witness Claimに追加コストが必要。
*   **クロック6**: 倫理監査役自身が黒カードの対象（「真実を見たが、黙っていた者」）となる。

### 議論停滞時の決着ルール（5分ルール）

PC同士の対立や、行動の選択肢（白カード化か暴露かなど）で議論が**5分以上**停滞した場合、またはプレイヤーが結論を出せない状態が続いた場合、GMは以下の処理を行う。

1. **文化財化処理（共犯）クロックを+1する**。
   *(人間が迷っている間にも、システムによる分類と無害化の「処理」は自動で進む。)*
2. GMは速やかに議論を打ち切り、以下のどちらかの手段でその場の処理を決着させる。
   * **A. ディレクター（PC1）による強行決定**：
     ディレクターが望む処理を決定する。ディレクターはペナルティとして「監査負債+1」を受ける。反対者はこの決定に対し、今回の矛盾を灰カードまたは黒カードに記録する権利を得る。
   * **B. 対立PC間でのダイス判定（スクリプト対決）**：
     対立する処理案を主張するPC同士で、最も妥当な能力値（例：脚本や演出）の対決判定（互いにダイスを振り、成功数の多い方が勝ち）を行う。勝者の案が採用される。敗者は「粗い演出カード」を1枚引き受けるか、または「共犯クロック+1」を受ける。

## 5. GMセクション：ノイズ・レキシコン

GMは現実混入率の数値を直接伝えず、NPCのセリフに「ノイズ語」を混ぜて警告する。
> [!CAUTION]
> **1セッション中にノイズが3回出たら、必ず現実混入イベントが発生する。**

*   **現実混入率 1〜2**: 「予定」「確認」「安全」の不自然な反復。「なんか設定と違いませんか？」
*   **現実混入率 3〜4**: 「まだ開けるな」「血の匂いがします」「あの人、台本にいないですよね？」
*   **現実混入率 5〜6**: 「本当に血が出ている」「警報は訓練ではありません」

## 6. P0テストプレイ用シナリオと検証項目

### 第1話「モール避難訓練」
*   **依頼**: 大型商業施設での避難訓練を成功演出する。
*   **表の目的**: 避難誘導の成功、模擬負傷者3名の救助、報道用映像の成立、公式ログ（白カード3枚）の固定。
*   **初期パラメータ**: 信憑性 3 / 現実混入率 1 / 監査負債 0 / 共犯クロック 0 / 予算 5
*   **初期ノイズ (灰カード)**: 「名簿にない女性がスタッフ動線にいる。彼女は『今日は訓練ではない』と言う」

### 【P0テスト検証項目 (合否基準)】
1. プレイヤーは白・灰・黒・粗い演出カードの違いを理解できたか。
2. **B級処理は使われたか。**（使われなかったならメリットが弱い）
3. **灰カードは放置されたか。**（全部すぐ処理されたなら腐爛圧が不適切）
4. **倫理監査役は沈黙したか。**（沈黙したなら共犯クロックの圧が足りない）
5. **ディレクターの強行決定は発生したか。**（発生しないなら現在と未来の対立が弱い）
6. **セッション終了時、白カードが「次回の檻」に見えたか。**
