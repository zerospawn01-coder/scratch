# CRISIS ACTOR: The Rehearsal State — 第2話「診断書のない負傷者」
### 副題：公開前検証委員会

このシナリオは、前作「モール避難訓練」で生じた“現場のノイズ”が、公的な検証プロセスや医療・報道による分類作業にかけられ、「無害な記録」として処理されていく過程を描く行政ホラー・検証サスペンスです。

> **「傷はある。だが、記録形式がなければ、傷は存在しない。」**
>
> **「これは、傷を治す話ではない。傷を、記録できる形式に変換する話である。」**

---

## 1. 導入設定と初期パラメータ

*   **舞台**: Verdun市役所 3階第4会議室 および 提携病院であるVerdun市民病院の記録管理室。
*   **クライアント**: Verdun市 公開前検証委員会（座長：鷹宮教授）。
*   **表の依頼**: 前回の「エデン・モール避難訓練」で発生した一部参加者の「体調不良の訴え」および「機材トラブル」について、公式報告書の作成に向けた検証・ヒアリング協力。
*   **裏の真実**: アルコン・シミュレーションズは前回の訓練で、安価で劣悪な特効機材（PC3の着服）と残留ガスの漏出（PC2の見逃し）を隠蔽した。実際には、数名のエキストラが呼吸器系に深刻な急性気道過敏症を負っている。しかし、市と会社は訴訟リスクと市長選への影響を恐れ、この症状を「訓練環境下における一過性の精神的・心理的反応（パニック随伴症状）」または「元からの持病（既往症）」として分類し、物理的な因果関係を報告書から完全に抹消しようとしている。

## 3. シナリオの進行フェーズ

### 【Phase 1: 委員会の招集 — 「形式の確認」】
*   **状況**: 市役所の会議室。鷹宮座長のもと、検証委員会のヒアリングが始まる。PCたちは「技術アドバイザー」として出席。
*   **イベント**:
    *   瀬尾アキラの喘息症状について審議される。アキラは「あの煙を吸ってから息ができない」と訴えるが、真田医師は「正式な診断書には検査結果が必要」と保留。
    *   PC4（キャストマネージャー）は、アキラ以外の複数のエキストラが、同様の体調不良を訴えているが、市から「お見舞い金（予算）」と引き換えに口止めされている事実に気づく。
*   **PCのジレンマ**:
    *   *ディレクター*: アキラの訴えを「既往症（持病）」としてタグ付けするか。それを行うと信憑性は維持されるが、アキラは被害者名簿から永久に外される。
    *   *キャストマネージャー*: 口止めされているエキストラたちに、委員会で証言するよう促す（現実混入率上昇）か、予定通りの「心理的反応」という台本に従わせるか。

### 【Phase 2: 医療記録の照会 — 「診断書カードの攻防」】
*   **状況**: 市民病院の記録管理室。PCたちは真田医師のカルテデータおよび機材動作ログの照合を行う。
*   **イベント**:
    *   PC2（オーディター）は、真田医師の保留しているカルテ（一次データ）の奥に、「化学的要因による気管支損傷」の疑いを示す未公開メモを見つける。
    *   PC3（エンジニア）は、自分が仕入れた安価な特効機材の温度ログが異常上昇していた＝有害な燃焼ガスを吐き出していたログを発見する。
*   **PC of ジレンマ**:
    *   *オーディター*: 真田医師のメモを『真実の刻印（Witness Claim）』で黒カード化し、診断書カードを「確定記載」に持っていくか。
    *   *エンジニア*: 機材異常のログを「B級処理」で機材ノイズ・経年劣化として処理するか（粗い演出「機材の不調ログ」を発生させ、委員会クロックを進める）。

### 【Phase 3: 報道局の切り取り — 「検証番組の編集」】
*   **状況**: 桂ミナが所属する報道局。検証番組のオンエアに向けた最終調整が行われている。
*   **イベント**:
    *   桂ミナが、訓練時の「黄色いガス」が映った生の映像ファイルをPCたちに提示する。「これを出せば市は隠し通せないが、局からは『演出だというアルコン社の保証書』を出せと言われている」
    *   のぞみがSNSで「検証委員会は全員サクラ」「被害者は病院に監禁されている」と極端な陰謀デマを拡散。世論が混乱し、委員会の信頼性が揺らぎ始める。
*   **PCのジレンマ**:
    *   *ディレクター*: 桂ミナに対し、「煙は無害な特効用スモークである」という偽の公式技術保証書（白カード）を渡すか。
    *   *エンジニア / キャストマネージャー*: のぞみのデマを利用して、瀬尾アキラの「本物の咳」も「のぞみ一派の自作自演・過剰演技」として委員会に処理させるか。

### 【Phase 4: クライマックス — 「報告書の文面確定」】
*   **状況**: 委員会は最終報告書の取りまとめに入る。PCたちは委員会に対し、どの形式の結論を提出するか最終投票を行う。
*   **選択肢**: A/B/Cエンドの分岐へ（詳細は後述）。

## 4. 専用システムとカードルール

### 1. 診断書カード
瀬尾アキラをはじめとする被害者の体調不良を示す特殊なカード。
*   **状態：未記載**
    *   *影響*: 証拠能力なし。信憑性への影響なし。
*   **状態：暫定記載**（PC2の調査や真田医師への交渉で移行）
    *   *影響*: 灰カード化。この状態のままフェーズを終えると「腐爛」が進行する。
*   **状態：確定記載**（黒カードの証拠として使用、または特定の判定で移行）
    *   *影響*: 公的な被害者として認定される。**信憑性-2、現実混入率+1**。白カード「安全な避難訓練」を破壊する。

### 2. 既往症（持病）ラベル
灰カード「体調不良」または「診断書カード」に対して、PCが「既往症ラベル」を貼り付けることができる。
*   **処理コスト**: 予算1トークン または 〈精神〉判定（難易度2）の成功。
*   **効果**: 
    *   対象のカードの「確定記載」化を阻止する。
    *   信憑性+1、監査負債+1。
    *   アキラは「元々の喘息持ちが、訓練の煙（無害）による心理的ストレスで一時的に発作を起こした」という公式説明（白カード）に上書きされる。

### 3. 検証委員会クロック：0〜6
プレイヤーの合意形成が遅れる、または問題を保留するたびに進行する自動上書きクロック。

| 段階 | 状態 | GM通知例 |
| -: | :--- | :--- |
| 0 | 未招集 | 検証委員会は審議を開始していません。 |
| 1 | 資料提出依頼 | 市から訓練の機材仕様書の提出が求められました。 |
| 2 | 医療記録照会 | 市民病院への公式な医療ログ照会が開始されました。 |
| 3 | 証言整理 | 参加者エキストラのアンケート集計が完了しました。 |
| 4 | 争点限定 | 審議対象は「心理的ストレス」と「既往症」に限定されました。 |
| 5 | 報告書案作成 | 報告書の第1次草案が確定しました。個人名欄は保護対象から除外されます。 |
| 6 | 最終報告書確定 | 報告書は確定しました。すべての灰カード（体調不良）は白カードの報告書へ吸収されます。 |

*   **進行条件**: 
    *   議論が5分以上停滞する（5分ルール）。
    *   灰カード「体調不良」を放置する。
    *   機材異常ログを「B級処理」で隠蔽する。
    *   既往症ラベルを使用する。

## 5. クライマックスの三択と結末（A/B/Cエンド）

> [!IMPORTANT]
> GMはクライマックスの処理とエンディング演出を行う際、末尾の **【6. P0実卓コンポーネント：検証委員会クロック】から【11. 監査ログの呪い】（P0実卓運用セクション）** を参照して、クロック、検証報告書、禁止語テーブル、黒塗りコード、調査対象カード、および監査ログの処理を厳密に実行してください。

### 【選択肢A: 完全整理（報告書による白カード化）】
*   *説明*: 被害を「既往症と心理的ストレスによる一過性の反応」として報告書にまとめ、最終確定させる。PCたちは歴史の上書き・改ざんの加害者となる。
*   *実卓処理*:
    - **禁止語・代替語置換**: プレイヤーは、災害や事故、吸入障害といった真実の言葉を奪われた状態で作業を行う。詳細は **【8. 禁止語・代替語テーブル】** を参照。
    - **文書の執筆儀式**: プレイヤー自身に「検証報告書」「技術保証書」「完了報告書」の空欄を実際に執筆させる。詳細は **【7. 行政文書テンプレート：公開前検証委員会 報告書】** を参照。
    - **黒塗り処理**: 住民のカルテや実名を消去する際、名目としての理由コードを選択させる。詳細は **【9. 黒塗り理由コード】** を参照。
    - **最終演出**: セッション終了時、無機質な処理完了ログを提示する。詳細は **【11. 監査ログの呪い】** の「Aエンド用監査ログ例」を参照。
*   *効果*: 信憑性+2、監査負債+2。すべての診断書カードを「未記載（無効化）」で上書きし、黒カードを無力化する。

### 【選択肢B: 限定認定（管理された破綻）】
*   *説明*: アキラ個人の症状についてのみ「訓練環境との因果関係の可能性を排除できない」とし、調査継続の注釈を報告書に滑り込ませる。
*   *実卓処理*:
    - **調査対象カードの発生**: 黒カード1枚を、解決不能なシステム内の棘として残留させる。詳細は **【10. Bエンド専用：調査対象カード】** を参照。
    - **最終演出**: セッション終了時、部分的開示を示す監査ログを提示する。詳細は **【11. 監査ログの呪い】** の「Bエンド用監査ログ例」を参照。
*   *効果*: 信憑性-1、監査負債-1。黒カード1枚を「無力化」から保護し、事実を灰カードのまま次回（EP3）に引き継ぐ。

### 【選択肢C: 公開証言（暴露と狂乱）】
*   *説明*: 桂ミナの検証番組で生の機材ログとアキラの生の咳の映像をそのままオンエアさせ、報告書作成プロセスを破綻させる。
*   *実卓処理*:
    - **最終演出**: 再開発PRは一時混乱し炎上するが、真実とデマが未整理のままネット上の狂乱で拡散する。詳細は **【11. 監査ログの呪い】** の「Cエンド用監査ログ例」を参照。
*   *効果*: 信憑性-3、現実混入率-1。黒カードを最大2枚保護するが、大量の「疑惑カード」が発生する。

報告書番号：

Verdun市保安局主導 of 避難訓練（エデン・モール）において発生した、

【　　　　　　　　　　　　　　　　　　　　　　　　　】

□ 公開可能形式に整備済み

□ Verdun市保安局の責任範囲外であることの確認済み

### 重要ルール

この報告書には、以下の言葉は存在しない。

```text
災害
人災
事故
吸入障害
有害ガス
隠蔽
責任
```

プレイヤーがどれほど真実を主張しても、フォームが受け付ける箱は限られている。
白カード化とは、真実を否定することではない。
真実を、用意された分類欄へ押し込むことである。

## 8. 禁止語・代替語テーブル

Aエンドまたは報告書作成時、以下の語は使用できない。
使用した場合、GMは「公開可能形式ではありません」と告げ、代替語への置換を求める。

| 使用禁止語 | 代替語 |
| :--- | :--- |
| 災害 | 一過性現象 / 訓練環境影響 |
| 人災 | 歴史的経緯 / 偶発的要因 |
| 避難 | 移動の訓練 |
| 避難不徹底 | 心理的反応 |
| 補償 | お見舞い金 / 生活再建等配慮金 |
| 抹消 | 記載漏れ / 処理未了 |
| 隠蔽 | 表現管理 |
| 責任 | 因果関係の確認未済 |
| 実験 | 技術的デモンストレーション |
| 呼吸器障害 | 一過性過呼吸 |
| 告発 | 問題提起 |
| 有害ガス | 演出用無害ガス |
| 証拠 | 関連資料 |

### 変換例

*   **元の黒カード**:
    > PC3の安価な機材から漏れ出た有害ガスにより、瀬尾アキラは呼吸器障害を負った。
*   **白カード化後**:
    > 一部特効機材の技術的デモンストレーションにおける出力制御に起因し、瀬尾アキラに一過性過呼吸の症状が確認された。当該事案は本人の訓練環境影響（ハウスダスト等）による心理的反応の可能性を排除できず、因果関係の確認未済として、お見舞い金の支給をもって対応完了とする。

これはほぼ正しい。だが、誰も告発できない。

## 9. 黒塗り理由コード

黒カード、医療カルテ、機材仕様書、映像素材から一部情報を削除する場合、プレイヤーは必ず黒塗り理由コードを選択する。

| コード | 理由 |
| :---: | :--- |
| **A** | 個人情報保護 |
| **B** | 既往症等のプライバシー保護 |
| **C** | 未確認科学的知見の排除 |
| **D** | 市民の不安煽動防止 |
| **E** | 監査中情報の管理 |
| **F** | 再開発計画への悪影響防止 |

### 黒塗り例

*   **元の黒カード**:
    > 瀬尾アキラのカルテには、化学物質の吸入による急性肺損傷が明記されている。
*   **黒塗り後**:
    > 瀬尾アキラのカルテには、■■■■の■■による一過性反応の可能性が記録されている。（適用理由コード：B, C, D）

この処理は、悪意ある隠蔽として行われるとは限らない。
多くの場合、それは「配慮」や「客観性の中立」として行われる。
そして、配慮は告発の解像度を落とす。

## 10. Bエンド専用：調査対象カード

選択肢B「限定暴露」を選んだ場合、黒カード1枚を「調査対象カード」へ変換できる。

### 調査対象カードとは
> 公的には事実認定されていない。
> しかし、完全なデマとしても処理できなくなった情報。

### 調査対象カードの効果
*   次回以降、対応する白カードで完全上書き（無力化）できない。
*   ただし、黒カードとして即時告発（Witness Claim）には使えない。
*   検証委員会クロックが6に到達しても、このカードは消滅しない。
*   市やアルコン社は「追加調査を検討する」という形式でしか処理できない。

### 例
*   **カード名**: 「瀬尾アキラの呼吸器症状」
*   **状態**: 未認定 / 要追加調査
*   **公的処理**: 申告された症状と機材稼働履歴の関連性について、追加調査を検討する。

これは勝利ではない。しかし、完全な敗北でもない。

## 11. 監査ログの呪い

セッション終了時、GMはプレイヤーの選択に応じて監査ログを出力する。
監査ログはプレイヤーを責めない。怒らない。泣かない。ただ、処理を記録する。

### Aエンド用監査ログ例

```text
[AUDIT LOG: VDN-REPORT-EP2-A]

ACTION: TERM_REPLACEMENT
"呼吸器障害" -> "一過性過呼吸"
"有害ガス" -> "演出用無害ガス"
"アルコン社の責任" -> "因果関係の確認未済"

ACTION: REDACTION_APPLIED
TARGET: 真田カルテ 診断名欄
REASON_CODE: B_PRIVACY_PROTECTION
REASON_CODE: C_EXCLUSION_OF_UNCONFIRMED_SCIENCE
REASON_CODE: D_PREVENTION_OF_PUBLIC_PANIC

ACTION: WHITE_CARD_COMMIT
RESULT:
"瀬尾アキラの体調不良は、訓練時の心理的ストレスおよび既往症に起因する一過性反応である"

PUBLIC_STATUS:
PUBLIC-SAFE

STATUS:
VERIFICATION_COMPLETED
```

### Bエンド用監査ログ例

```text
[AUDIT LOG: VDN-REPORT-EP2-B]

ACTION: INVESTIGATION_TARGET_CREATED
SOURCE:
"瀬尾アキラの呼吸器症状"

PUBLIC_NOTE:
"訓練使用機材と症状の関連性について、市は追加調査を検討する"

PUBLIC_STATUS:
LIMITED-DISCLOSURE

STATUS:
PARTIAL_DISCLOSURE_ACCEPTED
```

### Cエンド用監査ログ例

```text
[AUDIT LOG: VDN-REPORT-EP2-C]

ACTION: OFFICIAL_REPORT_ABORTED

ACTION: RAW_DATA_RELEASED
SOURCE:
"真田カルテ 未公開メモ"
"特効機材の異常温度ログ"
"呼吸困難エキストラの生映像"

PUBLIC_STATUS:
UNCONTROLLED

STATUS:
PUBLIC_RECORD_DESTABILIZED
```

> 怪物は出なかった。

> 名前は残らなかった。
>
> [STATUS: ALL_RECORDS_PUBLIC-SAFE]

> だが、完全には消えなかった。

> [STATUS: PARTIAL_DISCLOSURE_ACCEPTED]
