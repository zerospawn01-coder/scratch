# CRISIS ACTOR: The Rehearsal State — 第2話「診断書のない負傷者」
### 副題：公開前検証委員会

このシナリオは、前作「モール避難訓練」で生じた“現場のノイズ”が、公的な検証プロセスや医療・報道による分類作業にかけられ、「無害な記録」として処理されていく過程を描く行政ホラー・検証サスペンスです。

> **「傷はある。だが、記録形式がなければ、傷は存在しない。」**
>
> **「これは、傷を治す話ではない。傷を、記録できる形式に変換する話である。」**

---

## 1. 導入設定と初期パラメータ

*   **舞台**: Verdun市役所 3階第4会議室 および 提携病院であるVerdun市民病院の記録管理室。
*   **クライアント**: Verdun市 公開前検証委員会（座長：鷹宮教授）。
*   **表の依頼**: 前回の「エデン・モール避難訓練」で発生した一部参加者の「体調不良の訴え」および「機材トラブル」について、公式報告書の作成に向けた検証・ヒアリング協力。
*   **裏の真実**: アルコン・シミュレーションズは前回の訓練で、安価で劣悪な特効機材（PC3の着服）と残留ガスの漏出（PC2の見逃し）を隠蔽した。実際には、数名のエキストラが呼吸器系に深刻な急性気道過敏症を負っている。しかし、市と会社は訴訟リスクと市長選への影響を恐れ、この症状を「訓練環境下における一過性の精神的・心理的反応（パニック随伴症状）」または「元からの持病（既往症）」として分類し、物理的な因果関係を報告書から完全に抹消しようとしている。

## 3. シナリオの進行フェーズ

### 【Phase 1: 委員会の招集 — 「形式の確認」】
*   **状況**: 市役所の会議室。鷹宮座長のもと、検証委員会のヒアリングが始まる。PCたちは「技術アドバイザー」として出席。
*   **イベント**:
    *   瀬尾アキラの喘息症状について審議される。アキラは「あの煙を吸ってから息ができない」と訴えるが、真田医師は「正式な診断書には検査結果が必要」と保留。
    *   PC4（キャストマネージャー）は、アキラ以外の複数のエキストラが、同様の体調不良を訴えているが、市から「お見舞い金（予算）」と引き換えに口止めされている事実に気づく。
*   **PCのジレンマ**:
    *   *ディレクター*: アキラの訴えを「既往症（持病）」としてタグ付けするか。それを行うと信憑性は維持されるが、アキラは被害者名簿から永久に外される。
    *   *キャストマネージャー*: 口止めされているエキストラたちに、委員会で証言するよう促す（現実混入率上昇）か、予定通りの「心理的反応」という台本に従わせるか。

### 【Phase 2: 医療記録の照会 — 「診断書カードの攻防」】
*   **状況**: 市民病院の記録管理室。PCたちは真田医師のカルテデータおよび機材動作ログの照合を行う。
*   **イベント**:
    *   PC2（オーディター）は、真田医師の保留しているカルテ（一次データ）の奥に、「化学的要因による気管支損傷」の疑いを示す未公開メモを見つける。
    *   PC3（エンジニア）は、自分が仕入れた安価な特効機材の温度ログが異常上昇していた＝有害な燃焼ガスを吐き出していたログを発見する。
*   **PC of ジレンマ**:
    *   *オーディター*: 真田医師のメモを『真実の刻印（Witness Claim）』で黒カード化し、診断書カードを「確定記載」に持っていくか。
    *   *エンジニア*: 機材異常のログを「B級処理」で機材ノイズ・経年劣化として処理するか（粗い演出「機材の不調ログ」を発生させ、委員会クロックを進める）。

### 【Phase 3: 報道局の切り取り — 「検証番組の編集」】
*   **状況**: 桂ミナが所属する報道局。検証番組のオンエアに向けた最終調整が行われている。
*   **イベント**:
    *   桂ミナが、訓練時の「黄色いガス」が映った生の映像ファイルをPCたちに提示する。「これを出せば市は隠し通せないが、局からは『演出だというアルコン社の保証書』を出せと言われている」
    *   のぞみがSNSで「検証委員会は全員サクラ」「被害者は病院に監禁されている」と極端な陰謀デマを拡散。世論が混乱し、委員会の信頼性が揺らぎ始める。
*   **PCのジレンマ**:
    *   *ディレクター*: 桂ミナに対し、「煙は無害な特効用スモークである」という偽の公式技術保証書（白カード）を渡すか。
    *   *エンジニア / キャストマネージャー*: のぞみのデマを利用して、瀬尾アキラの「本物の咳」も「のぞみ一派の自作自演・過剰演技」として委員会に処理させるか。

### 【Phase 4: クライマックス — 「報告書の文面確定」】
*   **状況**: 委員会は最終報告書の取りまとめに入る。PCたちは委員会に対し、どの形式の結論を提出するか最終投票を行う。
*   **選択肢**: A/B/Cエンドの分岐へ（詳細は後述）。

## 4. 専用システムとカードルール

### 1. 診断書カード
瀬尾アキラをはじめとする被害者の体調不良を示す特殊なカード。
*   **状態：未記載**
    *   *影響*: 証拠能力なし。信憑性への影響なし。
*   **状態：暫定記載**（PC2の調査や真田医師への交渉で移行）
    *   *影響*: 灰カード化。この状態のままフェーズを終えると「腐爛」が進行する。
*   **状態：確定記載**（黒カードの証拠として使用、または特定の判定で移行）
    *   *影響*: 公的な被害者として認定される。**信憑性-2、現実混入率+1**。白カード「安全な避難訓練」を破壊する。

### 2. 既往症（持病）ラベル
灰カード「体調不良」または「診断書カード」に対して、PCが「既往症ラベル」を貼り付けることができる。
*   **処理コスト**: 予算1トークン または 〈精神〉判定（難易度2）の成功。
*   **効果**: 
    *   対象のカードの「確定記載」化を阻止する。
    *   信憑性+1、監査負債+1。
    *   アキラは「元々の喘息持ちが、訓練の煙（無害）による心理的ストレスで一時的に発作を起こした」という公式説明（白カード）に上書きされる。

### 3. 検証委員会クロック：0〜6
プレイヤーの合意形成が遅れる、または問題を保留するたびに進行する自動上書きクロック。

| 段階 | 状態 | GM通知例 |
| -: | :--- | :--- |
| 0 | 未招集 | 検証委員会は審議を開始していません。 |
| 1 | 資料提出依頼 | 市から訓練の機材仕様書の提出が求められました。 |
| 2 | 医療記録照会 | 市民病院への公式な医療ログ照会が開始されました。 |
| 3 | 証言整理 | 参加者エキストラのアンケート集計が完了しました。 |
| 4 | 争点限定 | 審議対象は「心理的ストレス」と「既往症」に限定されました。 |
| 5 | 報告書案作成 | 報告書の第1次草案が確定しました。個人名欄は保護対象から除外されます。 |
| 6 | 最終報告書確定 | 報告書は確定しました。すべての灰カード（体調不良）は白カードの報告書へ吸収されます。 |

*   **進行条件**: 
    *   議論が5分以上停滞する（5分ルール）。
    *   灰カード「体調不良」を放置する。
    *   機材異常ログを「B級処理」で隠蔽する。
    *   既往症ラベルを使用する。

## 5. クライマックスの三択と結末（A/B/Cエンド）

### 【選択肢A: 完全整理（報告書による白カード化）】
*   *説明*: 被害を「既往症と心理的ストレスによる一過性の反応」として報告書にまとめ、最終確定させる。
*   *演出*: プレイヤー全員で、報告書内の「一過性の心理的反応と判断された理由（黒塗りコード選択）」と、「被害者名の削除手続き」を実行する。
*   *効果*: 信憑性+2、監査負債+2。すべての診断書カードを「未記載（無効化）」で上書きし、黒カードを無力化する。
*   *監査ログ*: 
    ```text
    [AUDIT_LOG_SUCCESS] VERDUN_CITY_REPORT_EP2_A
    ・申告された全呼吸器症状について、訓練使用機材との因果関係は「なし」と判定。
    ・理由：個人環境（ハウスダスト、低気温）および演習による心理的動揺。
    ・本件は「処理完了」としてアーカイブされます。
    ```

### 【選択肢B: 限定認定（管理された破綻）】
*   *説明*: アキラ個人の症状についてのみ「訓練環境との因果関係の可能性を排除できない」とし、調査継続の注釈を報告書に滑り込ませる。
*   *演出*: 診断書カード1枚を「暫定記載」のまま保留し、未解決のシステムエラーとして次回のEP3へ引き継ぐ。
*   *効果*: 信憑性-1、監査負債-1。黒カード1枚を「調査対象カード」として残留させる。

### 【選択肢C: 公開証言（暴露と狂乱）】
*   *説明*: 桂ミナの検証番組で生の機材ログとアキラの生の咳の映像をそのままオンエアさせ、報告書作成プロセスを破綻させる。
*   *演出*: 報道による炎上が発生。アキラの咳がネット上の「陰謀デマ」と混ざり合い、真偽不明のままバズり散らかす。
*   *効果*: 信憑性-3、現実混入率-1。黒カード最大2枚を無傷で保護するが、大量の「疑惑カード」が発生する。
