# CRISIS ACTOR: The Rehearsal State — 第4話「公開記録審判」
### 副題：The Public-Safe Archive

このシナリオは、キャンペーン全体のクライマックス（最終話）です。EP1〜EP3でプレイヤーたちが積み上げてきた白カード、灰カード、黒カード、そして「監査ログ」そのものが裁きの場にかけられ、「どのような記録として歴史に残るか」を確定させる行政ホラー・アーカイブサスペンスです。

> **「記録は残った。だが、記録が残ることと、誰かが救われることは違う。」**
>
> **「あなたたちは真実を隠してきた。最後に、その隠蔽の記録だけが真実として残った。」**

---

## 1. 導入設定と初期パラメータ

*   **舞台**: 国家危機広報庁 公開記録審査室。防音とセキュリティ対策が施された、無機質な窓のない会議室。
*   **クライアント**: 国家危機広報庁（審査官：荒木タカシ）。
*   **表の依頼**: Verdun市および奥霧県で発生した一連の「大規模避難訓練」および「地域再生事業」に伴う関連記録（アルコン社の監査ログ含む）の統合と、情報公開法に基づく一般公開用「最終公開アーカイブ」の編纂。
*   **裏の真実**: 過去3話で発生したすべての事故、有害ガスの漏出、被害者の抹消、住民の身元虚偽記載といった「不都合な真実（黒カード）」の証拠が、アルコン社のシステムおよび関係者の手元に蓄積されている。広報庁は情報公開請求に対処するため、「すべての記録を法律に則って公開する」という姿勢を示すが、その真の目的は、すべての黒カード（証拠）を極限まで抽象化・要約・黒塗りすることで、「適切な手続きが行われた」という巨大な白カードに変換し、国家および関連企業の責任を恒久的に無害化・封印することである。

### 初期パラメータ
*   **信憑性**: 過去のセッションの最終値を引き継ぐ（デフォルト値：3）
*   **現実混入率**: 過去のセッションの最終値を引き継ぐ（デフォルト値：1）
*   **監査負債**: 過去のセッションの累積値を引き継ぐ（デフォルト値：3以上を想定）
*   **監査ログ開示クロック**: 0
*   **予算**: 過去の最終値を引き継ぐ（デフォルト値：3トークン）

### 過去セッションからの持ち込みカード
*   **【白カード群】**: EP1〜EP3で固定されたすべての白カード。これらは「崩し難い公的記録」として審査の前提となる。
*   **【黒カード群】**: 倫理監査役（PC2）が記録したすべての黒カード。これらは「公開請求されている未解決の真実」としてテーブルに並べられる。
*   **【調査対象カード群】**: EP2・EP3で「選択肢B」を選んだ場合に残留したシステム内の棘。

## 3. シナリオの進行フェーズ

### 【Phase 1: 記録の開示請求 — 「照会申請」】
*   **状況**: 国家危機広報庁の公開審査室。提出された過去3話のログの総点検が始まる。
*   **イベント**:
    *   外部のジャーナリストや市民団体から、Verdun市のモール災害、奥霧県の帳外帳に関する「公式記録の不一致」についての情報公開請求（開示請求）が届く。
    *   PC2（オーディター）の手元にある「黒カード（裏ログ）」が開示対象として名指しされる。
*   **PCのジレンマ**:
    *   *ディレクター*: 開示請求に対し、「公開範囲削減（理由コード適用）」を申請して黒カードの露出を防ぐか。これを行うと監査負債がさらに累積する。
    *   *オーディター*: 自分が握っている真実（黒カード）を「一般公開（PUBLIC）」の箱に叩き込むか、それとも「非公開（SEALED）」として取引の材料にするか。

### 【Phase 2: 要約版の作成 — 「表現調整の極み」】
*   **状況**: 会議室の大型モニターに、過去の監査ログと黒カードの文面が映し出され、審査官・荒木の手によって「公開可能形式」への変換作業が開始される。
*   **イベント**:
    *   PC3（エンジニア）の過去の「粗い演出カード」が、情報漏洩や法的処分の直接的な弱点として突きつけられる。
    *   荒木は「このまま公開すれば貴社は営業停止ですが、私が『適切な表現管理』を行えば、ただの技術デモンストレーションの不手際として処理できます」と持ちかける。
*   **PCのジレンマ**:
    *   *エンジニア*: 自分の弱点（粗い演出）を消すために、荒木の「表現管理（白カード化）」に同意するか。
    *   *キャストマネージャー*: 避難住民や失踪者遺族の生の証言テープを「未確認情報（MISINFO）」として処理し、ノイズを完全にカットするか。

### 【Phase 3: 利害関係者の合意 — 「監査負債の清算」**】
*   **状況**: 公開アーカイブの草案が完成。これ以上の修正が不可能な「確定前フェーズ」。
*   **イベント**:
    *   過去に累積した「監査負債」の数値がダイレクトに難易度として襲いかかる。監査負債が一定以上の場合、審査庁のシステムが自動的に「監査ログ開示クロック」を強制進行させる。
    *   クレイマー前局長や榊ミトが、PCたちに「この報告書で合意してくれ」と懇願する。彼らの利益（補償金やお見舞い金）は、この報告書が「適正」と判定されることと引き換えになっている。
*   **PCの対立**:
    *   真実を無加工で公開すれば、関係者は破滅し、被害者遺族もセカンドレイプ（のぞみの信者によるデマ攻撃）に晒される。
    *   美しく加工すれば、全員が救われるが、誰も加害者を告発できなくなる。

### 【Phase 4: 最終審判 — 「アーカイブ確定」】
*   **状況**: アーカイブの公開ボタンを押す瞬間。PCたちは最後の合意投票を行う。
*   **選択肢**: 最終的なA/B/Cエンドの確定（詳細は後述）。

## 4. 専用システムとカードルール

### 1. 公開区分カード
EP4では、場にあるすべての「黒カード」「灰カード（矛盾）」に対し、プレイヤーは以下のいずれかの「公開区分ラベル」を付与して分類しなければならない。

| 公開区分 | 定義 | システム上の効果 |
| :--- | :--- | :--- |
| **PUBLIC** | 一般公開 | 事実がそのまま公開される。**信憑性-2、現実混入率+1**。白カードを破壊する。 |
| **LIMITED** | 限定公開 | 学術研究・関係者のみ。**信憑性-1、監査負債-1**。灰カードのまま次回キャンペーンへ持ち越す。 |
| **SEALED** | 非公開保管 | 30年間封印。**信憑性+1、監査負債+2**。カードは無力化され、闇に葬られる。 |
| **MISINFO** | 誤情報処理 | デマ・ノイズとして破棄。**信憑性+2、現実混入率-1**。粗い演出カードをすべて消去する。 |
| **PUBLIC-SAFE**| 公開可能形式 | 禁止語置換と黒塗りを適用した「綺麗な真実」。黒カード1枚を巨大な白カードに吸収・消滅させる。 |

### 2. 監査ログ開示クロック：0〜6
プレイヤーが議論を引き延ばす、または都合の悪い証拠を保留するたびに自動進行するクロック。

| 段階 | 状態 | GM通知例 |
| -: | :--- | :--- |
| 0 | 内部参照のみ | 提出されたすべてのログは審査室内の極秘参照に留まっています。 |
| 1 | 照会申請 | メディアおよび市民団体からの公式な開示照会が申請されました。 |
| 2 | 部分開示審査 | 一部ログのヘッダー情報のみの仮公開が決定しました。 |
| 3 | 利害関係者通知 | 市・県・アルコン社等の利害関係者への最終合意勧告が送出されました。 |
| 4 | 公開範囲削減 | 個人情報・国家安全を理由とした、大規模な黒塗り処理が自動適用されました。 |
| 5 | 要約版作成 | 公開用要約版報告書の作成が完了しました。生のログはアーカイブから除外されます。 |
| 6 | 要約版のみ公開 | 最終報告書が確定し、公開されました。すべての黒カードはPUBLIC-SAFEとして白カードへ吸収されます。 |

*   **進行条件**: 
    *   議論が5分以上停滞する（5分ルール）。
    *   黒カードの分類決定を保留する。
    *   監査負債の清算（判定難易度上昇）に失敗する。

## 5. クライマックスの三択と結末（A/B/Cエンド）

> [!IMPORTANT]
> GMはクライマックスの処理とエンディング演出を行う際、末尾の **【6. P0実卓コンポーネント：監査ログの呪い】（P0実卓運用セクション）** を参照して、最終報告書の執筆、公開区分の確定、および監査ログの処理を厳密に実行してください。

### 【選択肢A: 統合アーカイブ化（完全なる白カード化）】
*   *説明*: すべての黒カードを「PUBLIC-SAFE」に分類し、完璧に黒塗りと禁止語置換が施された「最終報告書」を確定・公開する。
*   *実卓処理*:
    - **禁止語・代替語置換**: プレイヤーは過去3話すべての禁止語を使用不可のまま、最終白カード「関係機関による適切な手続きと公開の完了」を作成する。
    - **文書の執筆儀式**: プレイヤー自身に「国家危機広報庁 最終要約報告書」の空欄を執筆させる。
    - **効果**: 信憑性+3、監査負債+3。すべての黒カードを消滅させる。
*   *最終演出*: 詳細は **【6. 監査ログの呪い】** の「Aエンド：公開可能アーカイブ確定」を参照。

### 【選択肢B: 限定開示（不完全な継承）】
*   *説明*: 一部の黒カードを「LIMITED（限定公開）」または「PUBLIC」として保護し、完璧な隠蔽を拒否する。
*   *実卓処理*:
    - **カードの残留**: 黒カード最大2枚を「LIMITED」の状態でシステム内に保護し、次のキャンペーンまたは次回セッションへ「未解決のシステムエラー」として引き継ぐ。
    - **効果**: 信憑性-1、監査負債-1。
*   *最終演出*: 詳細は **【6. 監査ログの呪い】** の「Bエンド：限定開示承認」を参照。

### 【選択肢C: 監査ログ流出（記録の狂乱）】
*   *説明*: アルコン社の非公開監査ログ（生の黒カード）を、そのまま暗号化なしでネット上にリークさせ、公開審査プロセス自体を破綻させる。
*   *実卓処理*:
    - **効果**: 信憑性-3、現実混入率-2。白カードシステムが完全に崩壊し、すべての嘘が剥がれ落ちるが、世間にはのぞみの陰謀デマと同列の「おどろおどろしいお話」として消費される。
*   *最終演出*: 詳細は **【6. 監査ログの呪い】** の「Cエンド：システム監査ログの流出」を参照。

## 6. P0実卓コンポーネント：監査ログの呪い

セッション終了時、GMはプレイヤーの選択に応じて最終監査ログを出力する。
監査ログは感情を持たない。ただ、処理結果をアーカイブする。

- ALL_GRAY_CARDS -> ARTIFACT_NOISE (REMOVED)

- A_PERSONAL_INFO_PROTECTION (REMOVED: 104 NAMES)

ACTION: FINAL_WHITE_CARD_COMMIT

"Verdun市および奥霧県における一連の事案について、国家危機広報庁は適正かつ中立な検証手続きに基づき、記録の編纂と公開手続きを正常に完了した"

ALL_RECORDS_PUBLIC-SAFE

> 
> [STATUS: ALL_RECORDS_PUBLIC-SAFE]
