# CRISIS ACTOR: The Rehearsal State — 第3話「帳外神楽（ちょうがいかぐら）」
### 副題：超外神殻（ちょうがいしんかく）

このシナリオは、日本の土着信仰を「共同体が近代行政の公式記録（白カード）から消された事実を保存するための非公式分散ログシステム」として扱い、地方再開発PRの裏にある大規模災害の隠蔽と対峙する行政ホラー・ドキュメントスリラーです。

#### タイトルの意味

```text
帳外神楽：
  公的台帳の外に置かれた名前を、
  祭祀・口承・禁忌・地名が保存する話。

超外神殻：
  行政記録・文化財分類・PR映像・展示解説文・補償台帳という「殻」が、
  その保存された真実を優しく包み込み、
  告発不能な無害な文化資源へ変換・封印していく話。
```

*   **帳外神楽**: 村人が、公的記録から消し去られた人々の名前や危険な避難経路を、神楽の詞章（歌）や禁足地への禁忌に埋め込んで保存する行為（分散型口承ログシステム）。
*   **超外神殻**: 行政文書、文化財の分類名、観光PR映像、および監査ログといった公式システムが、その神楽を優しく包み込み、「告発不能な無害な文化資源」へと変換・封印する管理の外殻。

つまり**白カード・行政文書・展示パネル・PR映像・文化財登録票・移転完了報告書**、これらが「超外神殻」そのものである。その殻の中で、死者の名前は安全に保存される。ただし、二度と告発としては機能しない。

### 本シナリオの核心
> 恐怖の正体は、神でも、怨霊でも、祟りでもない。
> 誰も悪意を持っていないような顔で、死者の名前を「資料分類」「観光資源」「補償対象外」へと変換し、消去していく行政処理そのものである。
>
> **「これは、祟りを鎮める話ではない。告発を文化財に変換する話である。」**
>
> あなたたちは真実を隠すのではない。
> 真実を、公開可能な形式に整える。

## 1. 導入設定と初期パラメータ

*   **舞台**: 架空の山間限界集落「帳ノ沢村（ちょうのさわむら）」（奥霧県）。数年以内にダム湖の底に沈む予定。
*   **クライアント**: 奥霧県 地域再生局。
*   **表の依頼**: 「伝統文化保存ドキュメンタリー」の制作。村に伝わる「神隠し伝承」を神秘的な観光資源として演出し、円滑な住民移転と開発事業の成功を県内外にアピールする。
*   **裏の真実**: 30年前、帳ノ沢村で大規模な土砂崩れが発生した。県と開発企業は危険性を把握しながら開発を強行した事実を隠蔽するため、被害を「住民の自己責任（避難不徹底）」として処理し、一部の被害者世帯を公式の戸籍や避難者名簿から「抹消」した。
*   **都市伝説・陰謀論**: ネット上では「村人は全員役者」「反対派は排除された」「神隠しは県による創作伝承」などの噂が流れている。PCたちはこれらの極端な陰謀論を「煙幕」として逆に利用し、本物の告発を「妄想」として無力化することもできる。

## 2. 主要NPC

*   **榊 ミト（Mito Sakaki）**
    *   **立場**: 帳外神社の宮司代理（70代）。穏やかでPCたちに協力的な語り部。
    *   **秘密**: 台帳から消された人々の本名を記録した裏の古文書「帳外帳（ちょうがいちょう）」の守り手。
    *   **スタンス**: 「名前は消すな。だが、これ以上村を全国の見世物にしてかき回すのはやめてくれ」という静かな守護。
*   **春野 ソウ（So Haruno）**
    *   **立場**: 神楽を演じるために県が雇った若い代役俳優。
    *   **秘密**: 彼の祖父は30年前の災害で行方不明になったが、県の補償台帳では「県外移転済み」と虚偽記載されている。彼は役者として演技しながら、消された家族の生きた証を取り戻そうとしている。
*   **久堂 ノゾミ（Nozomi Kudo）**
    *   **立場**: ネットの陰謀論系ドキュメンタリー配信者。
    *   **特徴**: 一次データの収集能力は極めて高いが、極端な結論（「住民は全員役者」「村自体が巨大なセット」）をがなり立てる狂信者。
    *   **運用ルール**: **「のぞみは結論を3秒以上語らない。その代わり、画像・映像・音声・比較資料（一次データ）を必ず1つ場に出す。」** 彼女は推理を奪う探偵ではなく、扱いに困る汚染資料配布装置として機能する。
*   **「異物フレーム / 未分類フレーム」（旧・面の子）**
    *   **概要**: 撮影素材の端に、子ども用の面に見える数フレームの異物が混入する現象。
    *   **核心の描写**: **「面は祟っているのではない。誰かが、毎回置き直している。」**（面は霊ではなく、消し去られた歴史的な名前を映像に無理やり戻すための、共同体による手作業の物理ログである）。
    *   **3つの仮説**:
        1.  **機材干渉**: 神楽の鈴が鳴る特定の周波数が、古い撮影機材のセンサーに干渉して生じたパレイドリア現象（視覚の錯覚）。
        2.  **編集ミス**: 外部委託された安価な映像編集業者が、30年前の「存在しないはずの子供たち」のアーカイブ（Bロール）を誤って混入させた。
        3.  **人為的配置**: 村人が撮影が行われるたびに、子供用の面を意図的あるいは無意識に画角の端に置き続けている。

## 3. システムとカードルール

### 祭文（さいもん）カード
帳外神楽の歌詞や地名、禁足地の警告など、口承に埋め込まれた記録は「祭文カード」という特殊な灰カードとして扱われます。
*   **性質**: 表向きは「無害な伝統民俗」ですが、調査することで過去の行政不正を暴く「証拠（黒カードの素材）」に変化します。

#### 祭文カードの処理テーブル
| 選択した処理（アクション） | パラメータへの影響 | カード状態の変化 |
| :--- | :--- | :--- |
| **民俗文化として撮影する** | 信憑性+1、文化財化クロック+1 | 観光資源化され、黒カード（証拠）への変換が不可能になる。 |
| **迷信として編集でカットする** | 監査負債+1 | 白カード（公式事実）で上書きされ、その存在が消滅する。 |
| **内容を詳細に調査する** | 現実混入率+1 | 調査により「黒カード候補（裏ログ）」が発生する。 |
| **神楽として再演（リハーサル）する** | 予算-1 | 灰カードの腐爛の進行を1フェーズ止める（粗い演出カードが発生）。 |
| **無視して放置する** | なし | フェーズ終了時に自動的に腐爛段階が+1され、文化財化クロック+1。 |

### 異物フレームカード
映像に映り込んだ「子ども用の面」のノイズは、以下の灰カードとして扱います。
*   **【灰カード】「神楽映像の端に子ども用の面が数フレームだけ映っている」【腐爛0】**

#### 異物フレームカードの処理テーブル
| 選択した処理（アクション） | パラメータへの影響 | カード状態の変化とフレーバー |
| :--- | :--- | :--- |
| **機材ノイズとして処理する** | 文化財化クロック+1 | 白カード化しやすくなるが、粗い演出カード「機材異常の言い訳」が発生。 |
| **編集ミスとして処理する** | 監査負債+1、文化財化クロック+1 | 映像から完全に除去。外注編集業者へ全ての責任を転嫁する。 |
| **村人の仕込みとして調査する** | 現実混入率+1 | 共同体が意図的に残した痕跡として、黒カード候補（裏名簿）が発生。 |
| **民俗演出として採用する** | 信憑性+1 | 映像にそのまま残す。祭文カードの黒カード化（告発）が困難になる。 |

## 4. 久堂ノゾミのデータ散布ルール

久堂ノゾミは「結論を叫ぶNPC」ではなく、**「扱いに困る本物の一次データを無秩序にばらまく装置」**として運用します。彼女の主張自体はデタラメですが、彼女のカメラが向いている場所や拾い上げる一次データは本物です。

### のぞみの主張と一次データの対比マップ
| のぞみの主張（デタラメな極論） | 実際に映り込んでいる一次データ（本物の証拠） |
| :--- | :--- |
| 「この村は完全に県が作った観光用セットである」 | 県の過去のPR映像に出ている“村人”の一部が、県登録の再現映像アクター（代役）である。 |
| 「UFOの極秘着陸基地が山の奥に隠されている」 | 禁足地の立ち入り禁止エリアの奥に、県の古い「第4避難誘導実験区域」の看板がある。 |
| 「神社は県と結託したマインドコントロール施設だ」 | 神社の古い奉納帳に記載された人数と、県の公式移転台帳の住民数が一致しない（帳外帳の存在）。 |
| 「村人は全員、洗脳された役者で構成されている」 | 本物の住民と代役の役者が、同じ「公式想定問答集（台本）」の紙を手にして読んでいる。 |

### 疑惑カードの書式
*   **【疑惑カード】「帳ノ沢村は県が作った観光用セットである」**
    *   *的外れな結論*: 村という存在そのものが県の作った偽物であるという主張。
    *   *一次データ*: 映像に映る住民の一部が、県登録の再現映像アクターである事実。
    *   *利用価値*: 本物の住民が語る不都合な証言を、PC側が「あの人はのぞみの言う通り、大げさな演技をしているアクターだ」と偽装・処理するために利用できる。

## 5. シナリオの進行フェーズ

### 【Phase 1: ロケハン — 「再現される住民」】
*   **状況**: PCたちは帳ノ沢村に入り、県の用意したエキストラ住民と本物の住民が混ざり合う中で撮影を開始する。
*   **イベント**:
    *   PC4（キャストマネージャー）はインタビューの際、方言のイントネーションがあまりにも標準化されすぎている点から、出演住民の多くが「県が手配した代役アクター」であることに気づく。
    *   のぞみがSNS上に、過去の県のPR映像のキャプチャと、今回のインタビューに答える「住民」の顔を並べた無言の比較画像を投稿。ネット上で「村人は全員サクラだ」と炎上が始まる。
*   **PCのジレンマ**:
    *   *ディレクター*: 代役の使用を隠し通す（信憑性維持）か、「再現」と明記して陰謀論の的になるのを避けるか。
    *   *キャストマネージャー*: 本物の住民の生々しい語りを「代役の演技トーン」に強制的に揃えるか。それを行うと、さらに「血の通わない事務的な映像」になる。

### 【Phase 2: 帳外神楽 — 「避難経路の詞章」】
*   **状況**: 深夜、帳外神社の境内で神楽の撮影が行われる。
*   **イベント**:
    *   神楽の歌詞が死者の名前を呼ばず、地名や川のカーブ、石段の数を歌っていることが判明する。
    *   PC2（オーディター）が過去の地図と照合すると、この歌詞が「30年前の災害時、県が避難実験として強行し、結果的に隠蔽した本来の避難経路」の物理的な案内板になっていることに気づく。
    *   ミトが台本にない「名簿にない者から、先に橋を通しなさい」というセリフを囁く。
*   **PCのジレンマ**:
    *   *ディレクター*: そのセリフを「伝統の深み」としてそのまま採用し、告発のトリガーを残すか、カットするか。
    *   *エンジニア*: 音声編集でそのセリフだけを消去するか（粗い演出「消えた一節」が発生）。

### 【Phase 3: 禁足地ロケ — 「未分類フレーム」】
*   **状況**: 県の要請により、立ち入りが禁じられている「禁足地（かつての災害現場）」の神秘的なドローン空撮を試みる。
*   **イベント**:
    *   エンジニアのドローンが、鬱蒼とした森の奥に埋もれた古い錆びた看板を捉える。そこには `「第4避難誘導実験区域」` と書かれていた。
    *   機材トラブルが発生。神楽の鈴の音が鳴り響く特定の周波数が機材センサーに干渉し、パレイドリア現象によって偶然人の顔に見えるデジタルノイズ（異物フレーム）が画面の端に焼き付いてしまう。
*   **PCのジレンマ**:
    *   *エンジニア*: この「異物フレーム」を機材ノイズとしてCGで消去（B級処理）するか、伝統的演出として残すか。
    *   *オーディター*: 異物を残せば「消された人々の名前」が画面の端に残るが、消せば映像は「完璧にクリーンな観光資料」になる。

### 【Phase 4: クライマックス — 「帳外帳の処理」】
*   **状況**: 神社の奥に隠された「帳外帳（役場から消された住民の名簿）」をPCたちが発見する。県のドキュメンタリーが完成し、この帳外帳が「民俗資料」として博物館に寄贈・封印（証拠としての無力化）される直前、PCたちは最終決定を下さなければならない。

#### 住民たちの分断（道徳的ジレンマ）
*   **榊ミト**: 「名前は消すな。だが、これ以上村を全国の見世物にしてかき回すのはやめてくれ」
*   **若い移転住民**: 「補償金をもらって新しい町へ行く。もうこの村の暗い話は終わらせてほしい」
*   **失踪者遺族**: 「公的に死を受け入れ、名前を名簿に戻してほしい」
*   **県協力者（村の有力者）**: 「補償が滞りなく支払われるなら、帳外帳ごと『美しい伝統文化』として登録・処理してくれればそれでいい」
*   **代役俳優ソウ**: 「僕がこの神楽を完璧に演じきることでしか、祖父の名前を残す方法はないのか？」

## 6. クライマックスの三択と結末（A/B/Cエンド）

> [!IMPORTANT]
> GMはクライマックスの処理とエンディング演出を行う際、末尾の **【8. P0実卓コンポーネント：文化財化処理クロック】から【13. 監査ログの呪い】（P0実卓運用セクション）** を参照して、クロック、行政登録票、禁止語テーブル、黒塗りコード、調査対象カード、および監査ログの処理を厳密に実行してください。

### 【選択肢A: 民俗文化として白カード化する（完全偽装）】
*   *説明*: 帳外帳を「地域に伝わる美しい供養の民俗資料」として定義し、公式に博物館へ移管・封印させる。PCたちは歴史の上書き・改ざんの加害者となる。
*   *実卓処理*:
    - **禁止語・代替語置換**: プレイヤーは、災害や告発といった真実の言葉を奪われた状態で作業を行う。詳細は **【10. 禁止語・代替語テーブル】** を参照。
    - **文書の執筆儀式**: プレイヤー自身に「博物館展示解説文」「県PRナレーション」「完了報告書」の空欄を実際に執筆させる。詳細は **【9. 行政文書テンプレート：地域文化資料 登録票】** を参照。
    - **黒塗り処理**: 住民の実名を消去する際、名目としての理由コードを選択させる。詳細は **【11. 黒塗り理由コード】** を参照。
    - **最終演出**: セッション終了時、無機質な処理完了ログを提示する。詳細は **【13. 監査ログの呪い】** の「Aエンド用監査ログ例」を参照。
*   *効果*: 信憑性+2、監査負債+2。すべての祭文カードを無害な白カードで上書きし、黒カードを無力化する。

### 【選択肢B: 限定暴露（管理された破綻）】
*   *説明*: 映像の末尾に、災害に関する一部記録の不備と、県が追加調査を検討する旨の注釈を地味に挿入する。
*   *実卓処理*:
    - **調査対象カードの発生**: 黒カード1枚を、解決不能なシステム内の棘として残留させる。詳細は **【12. Bエンド専用：調査対象カード】** を参照。
    - **最終演出**: セッション終了時、部分的開示を示す監査ログを提示する。詳細は **【13. 監査ログの呪い】** の「Bエンド用監査ログ例」を参照。
*   *効果*: 信憑性-1、監査負債-1。黒カード1枚を「無力化」から保護し、事実を灰カードのまま次回に引き継ぐ。

### 【選択肢C: 撮影放棄（告発と狂乱）】
*   *説明*: ドキュメンタリー制作を放棄し、データを抱えて撤退し、帳外帳の生データをネット上に流出させる。
*   *実卓処理*:
    - **最終演出**: 再開発PRは破綻するが、真実とデマが未整理のまま狂乱のネット配信で拡散する。詳細は **【13. 監査ログの呪い】** の「Cエンド用監査ログ例」を参照。
*   *効果*: 信憑性-2、現実混入率-1。黒カードを最大2枚保護するが、白カード（公式の偽装）の作成には失敗する。

## 8. P0実卓コンポーネント：文化財化処理クロック

このシナリオでは、プレイヤーが迷い、議論し、判断を保留している間にも、行政処理は自動的に進行する。

怪異が近づくのではない。
資料が整っていく。

### 文化財化処理クロック：0〜6

| 段階 | 状態 | GM通知例 |
| -: | :--- | :--- |
| 0 | 未分類 | 資料「帳外帳」は未分類です。 |
| 1 | 資料整理中 | 関連資料の整理が開始されました。 |
| 2 | 仮分類完了 | 仮分類：地域信仰 / 災害記憶。 |
| 3 | 展示名確定 | 展示名候補が確定しました。 |
| 4 | 個人名削除 | 個人名欄は公開対象外として処理されました。 |
| 5 | 解説文確定 | 展示解説文が公開可能形式に整備されました。 |
| 6 | 文化財化完了 | 資料は文化財として登録されました。黒カード1枚を白カードへ吸収する。 |

### クロック進行条件

以下のいずれかが発生した場合、GMは文化財化処理クロックを+1してよい。

```text
・灰カードを放置した。
・祭文カードを「民俗文化として撮影する」で処理した。
・異物フレームを「機材ノイズ」または「編集ミス」として処理した。

・黒塗り理由コードを使用した。
・プレイヤーの議論が長時間停滞した。
・のぞみの一次データを回収せず、炎上を放置した。
```

### GM運用原則

文化財化処理クロックを進めるとき、GMは感情を込めない。

```text
県システム通知：
資料「帳外帳」の仮分類が完了しました。

分類：
地域信仰 / 災害記憶

公開区分：
学術研究限定
```

恐怖は、怒号や怪異ではなく、処理完了通知として訪れる。

### PRナレーション書き換えテンプレート：避難経路を「祈り」に変換する

登録票の記入と並行して、ディレクターは県PR映像のナレーション原稿を完成させなければならない。

GMはプレイヤーに以下の「元の祭文」を提示し、PRナレーションとして書き換えるよう指示する。

**元の祭文（Phase 2 で発見した避難経路の詞章）：**

```text
七つ目の石を踏んだら、立ち止まれ。
戻らぬ橋の手前で、南の窪地を探せ。
名簿にない者から、先に通せ。
```

**書き換えルール：**

以下の対応で変換すること。ただし「避難」「実験」「失踪」「補償」という語は使用禁止。

| 元の詞章の意味 | 許可された言い換え |
| :--- | :--- |
| 避難経路の分岐点 | 祈りの道しるべ／自然との対話 |
| 危険区域の境界標識 | 聖域との境界線／神の領域の入口 |
| 名簿から消された者 | 先人の魂／土地に宿る記憶 |
| 二次災害を防ぐ誘導 | 自然のリズムに従う暮らし |

**プレイヤーが書くPRナレーション原稿（穴埋め形式）：**

```text
帳ノ沢の神楽には、古くから伝わる【　　　　　】があります。

「七つ目の石、戻らぬ橋、南の窪地」。
この詞章には、自然と共に生きる村人たちの【　　　　　】が込められています。

先人たちは、【　　　　　】という形で、
この土地への深い敬意を次世代に伝えてきました。

帳ノ沢の神楽は、失われゆく日本の【　　　　　】を体現する、

```

**変換確認：**

原稿が完成したとき、GMは静かに確認する。

```text
「避難経路」という語は、最終原稿に残っていますか。
```

残っていなければ、白カード化は完了している。

### 重要ルール

この登録票には、以下の分類は存在しない。

```text
人災
隠蔽
行政抹消
補償漏れ
実験失敗
虚偽記録
告発
```

プレイヤーがどれほど真実を主張しても、フォームが受け付ける箱は限られている。
白カード化とは、真実を否定することではない。
真実を、用意された分類欄へ押し込むことである。

## 11. 黒塗り理由コード

黒カード、帳外帳、奉納者名簿、音声記録、映像素材から一部情報を削除する場合、プレイヤーは必ず黒塗り理由コードを選択する。

| コード | 理由 |
| :---: | :--- |
| **A** | 個人情報保護 |
| **B** | 遺族感情への配慮 |
| **C** | 地域差別防止 |
| **D** | 未確認情報の拡散防止 |
| **E** | 文化財保全上の中立性 |
| **F** | 係争中情報の非公開 |
| **G** | 観光利用上の表現調整 |
| **H** | 地域再生事業への影響防止 |

### 黒塗り例

*   **元の黒カード**:
    > 帳外帳は、公的記録から消された住民名簿である。榊家三名は、30年前の避難誘導実験区域で死亡した。
*   **黒塗り後**:
    > 帳外帳は、帳ノ沢地域に伝わる地域信仰に関する資料である。■■家■■名は、■■年前の■■■■に関連する帳外対象者として記録されている。（適用理由コード：A, B, E）

この処理は、悪意ある隠蔽として行われるとは限らない。多くの場合、それは「配慮」として行われる。そして、配慮は告発の解像度を落とす。

## 12. Bエンド専用：調査対象カード

選択肢B「限定暴露」を選んだ場合、黒カード1枚を「調査対象カード」へ変換できる。

### 調査対象カードとは
> 公的には事実認定されていない。
> しかし、完全なデマとしても処理できなくなった情報。

### 調査対象カードの効果
*   次回以降、対応する白カードで完全上書き（無力化）できない。
*   ただし、黒カードとして即時告発（Witness Claim）には使えない。
*   文化財化処理クロックが6に到達しても、このカードは消滅しない。
*   県やアルコン社は「追加調査を検討する」という形式でしか処理できない。

### 例
*   **カード名**: 「帳外帳と県移転台帳の人数差」
*   **状態**: 未認定 / 要追加調査
*   **公的処理**: 過去の記録不備について、関係資料の確認を検討する。

これは勝利ではない。しかし、完全な敗北でもない。
