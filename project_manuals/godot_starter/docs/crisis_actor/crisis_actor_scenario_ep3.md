# CRISIS ACTOR: The Rehearsal State — 第3話「帳外神楽（ちょうがいかぐら）」

このシナリオは、日本の土着信仰を「共同体が近代行政の公式記録（白カード）から消された事実を保存するための非公式分散ログシステム」として扱い、地方再開発PRの裏にある大規模災害の隠蔽と対峙するドキュメントスリラーです。

---

## 1. 導入設定と初期パラメータ

*   **舞台**: 架空の山間限界集落「帳ノ沢村（ちょうのさわむら）」（奥霧県）。数年以内にダム湖の底に沈む予定。
*   **クライアント**: 奥霧県 地域再生局。
*   **表の依頼**: 「伝統文化保存ドキュメンタリー」の制作。村に伝わる「神隠し伝承」を、美しく神秘的な観光資源として演出し、円滑な住民移転と開発事業の成功を県内外にアピールする。
*   **裏の真実**: 30年前、帳ノ沢村で大規模な土砂崩れが発生した。県と企業は危険性を把握しながら開発を強行した事実を隠すため、被害を「住民の自己責任（自主避難の不徹底）」として処理し、一部の被害者世帯を公式の戸籍や避難者名簿から「抹消」した。
*   **都市伝説・陰謀論**: ネット上では「村人は全員役者」「反対派は排除された」「神隠しは県による創作伝承」などの過激な噂が流れている。PCたちはこれらの極端な陰謀論を逆に利用し、本物の告発を「妄想」として無力化することもできる。

### 初期パラメータ
*   **信憑性**: 3
*   **現実混入率**: 1
*   **監査負債**: 1
*   **共犯クロック**: 0
*   **機材劣化**: 0
*   **予算**: 5トークン

### 最初から場に出すカード
*   **【白カード】「帳ノ沢村の住民移転は、県と住民の合意に基づき円満に進行している」**
    *   *影響*: 住民の不満や抗議は「公式には存在しない」前提となる。
*   **【灰カード】「名簿の不一致」【腐爛0】**
    *   *内容*: 県の移転同意者名簿と、地元の帳外神社にある奉納者名簿の人数が一致しない。

## 2. 主要NPC

*   **榊 ミト（Mito Sakaki）**
    *   **立場**: 帳外神社の宮司代理（70代）。穏やかでPCたちに協力的な語り部。
    *   **秘密**: 台帳から消された人々の本名を記録した裏の古文書「帳外帳（ちょうがいちょう）」の守り手。
    *   **口癖**: 「役場にない名前は、神さまのほうで預かります」
*   **久堂 ノゾミ（Nozomi Kudo）**
    *   **立場**: ネットの陰謀論系ドキュメンタリー配信者。
    *   **特徴**: 一次データの収集能力は極めて高いが、極端な結論（「住民は全員役者」「村自体が巨大なセット」）をがなり立てる狂信者。彼女の極論自体はデタラメだが、彼女がSNSに投稿する「無言の比較画像」や「配信の隅の映り込み」といった生データ自体は本物であるため、プレイヤーは彼女の極論を煙幕として利用しつつも、ばら撒かれる一次データの隠蔽・回収に追われることになる。
*   **春野 ソウ（So Haruno）**
    *   **立場**: 神楽を演じるために県が雇った若い代役俳優。
    *   **秘密**: 彼の祖父は30年前の災害で行方不明になったが、県の補償台帳では「県外移転済み」と虚偽記載されている。彼は役者として演技しながら、消された家族の生きた証を取り戻そうとしている。
*   **「面の子（おめんのこ）」**
    *   **演出**: 映像の隅に映り込む、仮面をつけた子供のような影。オカルト的な怪異ではなく、徹底して合理的な「システム上のバグ」や「人為的な執念」として表現される。神楽の鈴の周波数が古い撮影センサーに干渉して発生したパレイドリア現象（錯覚）や、安価な外注編集業者が起こした編集ミスによる過去アーカイブの数フレームの紛れ込み、あるいは撮影のたびに村人が画角の端に物理的にお面を置き続けるという人間の執念などとして描写される。

## 3. 専用システム：祭文（さいもん）カード

帳外神楽の歌詞や地名、禁足地の警告など、口承に埋め込まれた記録は「祭文カード」という特殊な灰カードとして扱われます。

*   **性質**: 祭文カードは、表向きは「無害な伝統民俗（灰カード）」ですが、調査することで過去の行政不正を暴く「証拠（黒カードの素材）」に変化します。

### 祭文カードの処理テーブル

| 選択した処理（アクション） | パラメータへの影響 | カード状態の変化 |
| :--- | :--- | :--- |
| **民俗文化として撮影する** | 信憑性+1 | 観光資源化され、黒カード（証拠）への変換が不可能になる。 |
| **迷信として編集でカットする** | 監査負債+1 | 白カード（公式事実）で上書きされ、その存在が消滅する。 |
| **内容を詳細に調査する** | 現実混入率+1 | 調査により「黒カード候補（裏ログ）」が発生する。 |
| **神楽として再演（リハーサル）する** | 予算-1 | 灰カードの腐爛の進行を1フェーズ止める（粗い演出カードが発生）。 |
| **無視して放置する** | なし | フェーズ終了時に自動的に腐爛段階が+1される。 |

## 4. シナリオの進行フェーズ

### 【Phase 1: ロケハン — 「村人役」】
*   **状況**: PCたちは帳ノ沢村に入り、県の用意したエキストラ住民と本物の住民が混ざり合う中で撮影を開始する。
*   **イベント**:
    *   PC4（キャストマネージャー）はインタビューの際、方言の不自然さから、出演者が「身元の怪しい代役」であることに気づく。
    *   陰謀論者ノゾミが、SNS上に「過去の県の別事業PR映像」と「今回の移転同意者インタビュー」の静止画を並べた無言の比較画像を投稿。フォロワーたちが「全員役者の仕込み」「村自体が巨大なセットだ」と極端な陰謀論を拡散し始めるが、比較画像内の「顔の一致」という一次データは本物であるため無視できない。
*   **PCのジレンマ**:
    *   *ディレクター*: 代役の使用を隠し通す（信憑性維持）か、「再現」と明記して陰謀論の的になるのを避けるか。
    *   *キャストマネージャー*: 本物と代役の「演技」を揃えようとするが、揃えすぎると逆に「不自然に統率された仕込み」として切り抜かれる。
*   **発生するカード**:
    *   **【灰カード】「インタビューの代役」【腐爛0】**
    *   **【疑惑カード（ノゾミの配信）】「住民は全員役者である」**

### 【Phase 2: 帳外神楽 — 「名前を呼ばない祭り」】
*   **状況**: 深夜、帳外神社の境内で神楽の撮影が行われる。
*   **イベント**:
    *   神楽の詞章が、死者の名前を直接呼ばず、地名や川のカーブ、石段の数を歌っていることが判明する。
    *   PC2（オーディター）が過去の地図と照合すると、この詞章が「30年前の災害時、県が隠蔽した本来の避難経路」の案内板になっていることに気づく。
    *   宮司代理のミトが台本にないノイズ台詞「名簿にない者から、先に通しなさい」と囁く。
*   **PCのジレンマ**:
    *   *ディレクター*: ミトの不穏なセリフを「伝統の深み」としてそのまま採用するか（黒カードのトリガーになる）、カットするか。
    *   *エンジニア*: 音声編集でそのセリフだけを不自然に消去するか（粗い演出カード「消えた一節」が発生）。
*   **発生するカード**:
    *   **【祭文カード】「戻らぬ橋、南の窪地」【腐爛0】**

### 【Phase 3: 禁足地ロケ — 「入ってはいけない山道」】
*   **状況**: 県の要請により、立ち入りが禁じられている「禁足地（かつての災害現場）」の神秘的なドローン空撮を試みる。
*   **イベント**:
    *   エンジニアのドローンが、鬱蒼とした森の奥に埋もれた古い錆びた看板を捉える。そこには県の名前と、アルコン社の旧ロゴで `「第4避難誘導実験区域」` と書かれていた。
    *   ノイズ3回ルール、または1の出目により、機材トラブルが発生。神楽の鈴が鳴る特定の周波数が撮影機材のセンサーに干渉してデジタルノイズが発生し、それがパレイドリア現象（視覚の錯覚）によって偶然人の顔（面の子）のように画面に焼き付いてしまう。
*   **PCのジレンマ**:
    *   *エンジニア*: 看板をCGで消去（B級処理）するか、そのまま映像に残すか。
    *   *オーディター*: 土着の禁足地が「過去の人体避難実験」の隠蔽エリアである証拠（黒カード）として記録するか。
*   **発生するカード**:
    *   **【灰カード】「禁足地の旧実験標識」【腐爛0】**
    *   **【黒カード候補】「神隠し伝承の正体は実験失敗による抹消」**

### 【Phase 4: クライマックス — 「帳外帳」】
*   **状況**: 神社の奥に隠された「帳外帳（役場から消された住民の名簿）」をPCたちが発見する。県のドキュメンタリーが完成し、この帳外帳が「民俗資料」として博物館に寄贈・封印される（証拠としての無力化）直前、PCたちは最終決定を下さなければならない。

#### 選択肢A: 民俗文化として白カード化する（完全偽装）
*   *説明*: 「帳外帳は、地域に伝わる美しい供養の民俗資料である」と映像内で定義し、歴史の上書き・改ざんの加害者となる道を選ぶ。
*   *演出（エンディング）*:
    - **歴史の改ざん（加害ロールプレイ）**: プレイヤー自身に、博物館に掲示される解説パネルのテキストを執筆させる。そこでは「消された被害者たちの実名」を、五穀豊穣を願う「架空の神々の名前」へと書き換えさせ、彼らの生存の痕跡を公式に抹消する。
    - **血の通わない事務的感謝**: 県の担当者から「地域のナラティブの最適化にご協力いただき感謝します」という、極めて事務的で冷淡な感謝状（電子メール）が送られてくる。
    - **文化の去勢（完成したPR映像）**: 完成した美しいPR映像の中で、神楽が完璧に演じられている。しかし、本来は「避難経路」を指していたはずの歌詞の伝承（祭文）が、いつの間にか「県を賛美する無害な観光用の歌詞」にすり替わっている。また、もし村人自身が「これ以上波風を立てず、白カードとして処理してほしい（忘れたい）」と望んでいる場合、この隠蔽は「善意の暴力」となり、PCたちに抵抗すら諦めさせたシステムへの加担と罪悪感を残す。
*   *効果*: 信憑性+2、監査負債+2。すべての祭文カードを無害な白カードで上書きし、黒カードを無力化する。

#### 選択肢B: 限定暴露（管理された破綻）
*   *説明*: 「過去の土砂災害に関する一部記録の不備について、県は追加調査を検討する」という注釈を映像末尾に入れる。
*   *効果*: 信憑性-1、監査負債-1。黒カード1枚を「無力化」から保護し、事実を灰カードのまま次回に引き継ぐ。

#### 選択肢C: 撮影放棄（告発と破綻）
*   *説明*: 編集データを抱えて撤退し、帳外帳のデータを外部に流出させる。
*   *効果*: 信憑性-2、現実混入率-1。黒カードを最大2枚保護するが、県との契約は即座に破綻し、ディレクターのキャリアは終了する。
