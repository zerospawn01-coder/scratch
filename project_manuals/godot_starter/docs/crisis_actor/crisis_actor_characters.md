# CRISIS ACTOR: The Rehearsal State — キャラクター・アーキタイプ

本作におけるプレイヤーキャラクター（PC）は、危機演出会社「アルコン・シミュレーションズ」に所属するスペシャリストたちです。
各PCは、共通の4能力値（脚本・演出・情報・精神）を異なる配分で持ち、固有のアクティブスキル（能力）とパーソナル・シークレット（秘密と勝利条件）を抱えています。

---

## 4つの基本能力値
*   **脚本**: 演出の妥当性、台本の整合性、論理的説得。
*   **演出**: 特効機材の操作、キャストの誘導、現場での即興アクション。
*   **情報**: 物的証拠の調査、カメラ・通信機器の操作、データの記録・隠蔽。
*   **精神**: NPCへの心理誘導、緊迫した交渉、恐怖やノイズへの抵抗。

## PC1：ディレクター（演出統括者）
> **「私の仕事は、彼らに『完璧な避難』という最高のショーを提供することだ」**

*   **役割**: 現場の指揮を執り、タイムライン通りに「公式の真実（白カード）」を固定する責任者。
*   **能力値**: 脚本: 3 / 演出: 3 / 精神: 2 / 情報: 1

### 【キャラクター能力】
*   **「強行決定（Executive Decision）」**
    *   **効果**: 異議申立ラウンドが発生した際、GMに「監査負債+1」を宣言することで、他のPCの異議を強制的に却下し、自分の望む「演出（白カードの方向性）」を即座に決定できる。
*   **「信憑性の仮面（Mask of Credibility）」**
    *   **効果**: 判定での失敗（成功数不足）による「信憑性-1」が発生した際、予算を1トークン消費することでそれを打ち消し、代わりに「灰カード（ただの不手際）」の発生へと変換できる。

### 【パーソナル・シークレット（秘密と葛藤）】
*   **『完璧な悲劇の不在』**
    *   **背景**: 3年前、自分が演出した「化学プラント避難演習」で本物のガス漏れが発生した。彼はそれを「演出の一部」として強行処理したが、結果として数名が後遺症を負った。会社はその事実をもみ消し、彼を守った。彼は二度と「演出の破綻」を許さない。
    *   **勝利条件**: セッション終了時、白カード「完璧な避難訓練モデル」が固定されており、かつ「監査負債」が2以下であること。

## PC2：オーディター（倫理監査役）
> **「私は真実の味方ではない。ただ、未来のログに嘘が混ざるのを防ぐだけだ」**

*   **役割**: 演出の記録とログの正当性を監視する、冷徹な監査役。
*   **能力値**: 情報: 3 / 精神: 3 / 脚本: 2 / 演出: 1

### 【キャラクター能力】
*   **「真実の刻印（Witness Claim）」**
    *   **効果**: 灰カード（矛盾）が発生した際、または「共犯クロック」が3未満の時、その灰カードを即座に「Black Ledger（黒カード）」へ封印できる。共犯クロックが3以上の場合は、予算を1トークン消費しなければこの能力を使えない。
*   **「監査の楔（Audit Stake）」**
    *   **効果**: 誰かの判定後、ダイスの出目「1（ノイズ）」の数を1つ減らす、または増やすことができる。この能力を使用するたび、自身の「共犯クロック」を+1するか、予算を1トークン消費する。

### 【パーソナル・シークレット（秘密と葛藤）】
*   **『遺されたノイズ』**
    *   **背景**: 今回の訓練現場であるエデン・モールで、3ヶ月前、あなたの元協力者であるクララの姉「エリナ・ヴァンス」が不審死した。クララはあなたに助けを求めていたが、あなたは社内での保身のために彼女を見捨てた形になっている。いま、クララは姉の死の証拠データを持ってエデン・モールに潜入している。
    *   **勝利条件**: クララやエリナの死の真相に関する黒カードを1枚以上作成し、それに対応する白カードによる「完全無力化（情報否定）」を防ぐこと。

## PC3：エンジニア（特効技術者）
> **「火薬の量を半分にすれば安全だが、絵面が安っぽくなる。…どっちにする？」**

*   **役割**: 特殊効果、爆薬、煙霧、通信妨害など、現場の物理的な演出をコントロールする技術者。
*   **能力値**: 演出: 3 / 情報: 3 / 精神: 2 / 脚本: 1

### 【固有ゲージ：機材劣化クロック（0〜3）】
PC3が特殊な加工や強引な機材操作を行うたびに上昇するリスクゲージ。
*   **「B級の極み」を使用する**: クロック+1
*   **「Controlled Chaos」を使用する**: クロック+1
*   **クロックが3に達した場合**: 即座にクロックは0にリセットされ、GMは以下のどちらかを発生させる。
    *   *A. 場にあるPC3の「粗い演出カード」を即座に【腐爛1】の灰カードに変換する（なければBを適用）*
    *   *B. 現実混入率+1*

### 【キャラクター能力】
*   **「職人肌の妥協（B級の極み）」**
    *   **効果**: 判定前に「B級処理」を宣言する場合、ダイスプール（振るダイスの数）を+1個する。さらに、彼が発生させた「粗い演出カード」は、他のPCが修正・隠蔽する際のコスト（予算や判定難易度）を-1する。使用時、**機材劣化クロック+1**。
*   **「制御された暴発（Controlled Chaos）」**
    *   **効果**: 現実混入率が上昇するイベントが発生した際、予算を1トークン消費することで、その被害を他のエリアへ誘導するか、または「信憑性+1」へと変換できる。使用時、**機材劣化クロック+1**。

### 【パーソナル・シークレット（秘密と葛藤）】
*   **『安価な安全』**
    *   **背景**: あなたは会社の演出予算を浮かせて着服するため、今回の爆薬やスプリンクラー制御装置を非合法ルートから安価で仕入れた粗悪品に変えている。完璧な演出をしようとすれば機械が自壊し、現実混入を招く。
    *   **勝利条件**: セッション終了時に、自分が関与した「粗い演出カード」が場に1枚以上残っていること（これが残っていないと、予算が適正に使われたことになり、着服の監査が入る）。

## PC4：キャストマネージャー（キャストリーダー）
> **「泣き叫ぶ避難民たちを見て。彼らは本物よ。私がそう演じさせているから」**

*   **役割**: サクラ（エキストラ）や現場アクターたちを指揮し、現場の「空気感」と「世論」を操作する演出家。
*   **能力値**: 演出: 3 / 精神: 3 / 脚本: 2 / 情報: 1

### 【キャラクター能力】
*   **「サクラの統率（Crowd Control）」**
    *   **効果**: 避難民NPCたちの動揺を鎮め、演出通りに動かす判定（精神または演出）を行う際、難易度を-1する（最低1）。
*   **「ノイズの調律（Noise Tuning）」**
    *   **効果**: フェーズ終了時、灰カードの「腐爛段階」が進行する際、予算を1トークン消費することで、その進行を別の灰カードに移し替えるか、または進行を1フェーズだけ遅らせることができる。

### 【パーソナル・シークレット（秘密と葛藤）】
*   **『台本なき血縁』**
    *   **背景**: 今回の「モール避難訓練」の一般エキストラの中に、あなたの身内（あるいはかつて守ると誓った大切な人物）が紛れ込んでいる。彼らは本当にこのモールで「何かが起きている」と怯え始めている。
    *   **保護対象カードの設定**: ゲーム開始時、PC4は以下のテンプレートを記入し、GMにのみ開示する。

#### 保護対象カード（PC4専用）
*   **名前**: （自由に決定）
*   **表向きの役割**: エキストラ避難民
*   **PC4との関係**: （弟、娘、親友など、大切な人物）
*   **今どこにいるか**: 一般避難民グループの最前線
*   **この人物が負傷すると発生する灰カード**: `「親族の悲鳴：避難民の1人が演出の嘘を見抜き、パニックを起こして周囲に叫んでいる」【腐爛1】`

*   **勝利条件**: セッション終了時まで、自身の「保護対象」となった人物を生存させ、かつ「負傷（灰カード化）」させないこと。
