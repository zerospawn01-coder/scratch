# CRISIS ACTOR P0

Godot 4 project scaffold for the CRISIS ACTOR P0 test package.

## Open

1. Launch Godot.
2. Choose **Import**.
3. Select `project.godot` in this folder.
4. Open the project and run `scenes/main.tscn`.

## Layout

- `scenes/`: game scenes.
- `scripts/`: GDScript files.
- `assets/`: sprites, audio, fonts, and other imported resources.
- `addons/`: Godot plugins.
- `docs/crisis_actor/`: copied P0 test documents.

## Viewer

- Right-side TOC jumps to headings.
- Search is literal, not regex.
- Search highlights are rebuilt from raw text on every refresh.
- Quick-search buttons cover the P0 terms used most often at the table.
- The TOC collapses automatically on narrower layouts and can be toggled manually.

## Notes

Godot's `.godot/` folder is local cache and is ignored by Git.
The first screen is a plain document viewer for the rulebook, character sheets, scenario, walkthrough, implementation plan, and task notes.
